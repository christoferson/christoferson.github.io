Claude API

ReferenceMessages API fields, tool use, structured output and batches.

TermMeaningCovered in
messagesThe full conversation, sent on every request; the API keeps no state1.1, 5.1
stop_reasonWhy a response ended: end_turn, tool_use, max_tokens, stop_sequence, pause_turn, refusal, model_context_window_exceeded1.1
tool_use blockClaude's request to call a tool: an id, the tool name and its input1.1
tool_result blockYour answer to a tool call, in the next user message, matched by tool_use_id1.1
is_errorFlag on a tool result that tells Claude the call failed (MCP's isError maps to it)2.2
tool_choiceauto, any, a named tool or none; forcing is rejected (400) by the newest models2.3, 4.3
disable_parallel_tool_useInside tool_choice: at most one tool call per response2.3

output_config.formatJSON outputs: a plain reply guaranteed to match a schema; can't be combined with citations4.3

Architecture patterns

ReferenceThe exam's vocabulary for designs and anti-patterns.

TermMeaningCovered in
Hub and spokeA coordinator routes all communication; subagents never talk to each other1.2
Prerequisite gateCode that blocks a tool until an earlier step succeeded1.4
Prompt chainingA fixed sequence of calls, each on the previous output, with checks between1.6
Dynamic decompositionSubtasks chosen at run time from what's been found1.6
Multi-pass reviewPer-file local passes plus a cross-file integration pass4.6
Independent instanceA reviewer without the generator's reasoning context4.6
Interview patternClaude asks you questions and writes the spec before building3.5
Case facts blockExact amounts, dates and statuses kept outside the summarised history5.1
Lost in the middleMaterial in the middle of a long input is more likely to be missed5.1
Progressive summarisationRepeated condensing of history, which blurs numbers and dates5.1
Scratchpad fileFindings written to disk and consulted instead of remembered5.4
ManifestA record of each agent's status and state file, loaded to resume after a crash5.4
Silent suppressionReturning a failure as an empty success; an anti-pattern5.3
Coverage annotationLabelling each topic as well supported, thin or a gap in the final report5.3
CalibrationSetting confidence thresholds from a labelled validation set5.5
Stratified samplingA random sample from each document type, so rare types are audited5.5
Claim-source mappingEach claim kept with its source, excerpt, date and method5.6
Policy gapA request policy doesn't cover; an escalation trigger5.2
