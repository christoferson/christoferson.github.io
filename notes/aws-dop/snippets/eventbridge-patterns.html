EventBridge event patterns

Event patterns for pipeline failures, security findings, compliance changes, API calls, Health events, Auto Scaling and ECS. Each snippet shows when to use it, the code with comments, and the detail that usually decides the exam answer.

  1. A CodePipeline execution failed
  2. High-severity GuardDuty finding
  3. A resource became noncompliant in AWS Config
  4. A specific API call, from CloudTrail
  5. An exposed access key (AWS Health)
  6. Auto Scaling failed to launch an instance

Patterns match on any field of the event. Values in a list are ORed; separate fields are ANDed. The // comments are annotations only: JSON doesn't allow comments, so remove them before use.

A CodePipeline execution failed

Use whenNotifying the team or opening a ticket when any pipeline fails.

{
  "source": ["aws.codepipeline"],
  "detail-type": ["CodePipeline Pipeline Execution State Change"],
  "detail": {
    "state": ["FAILED"],
    "pipeline": ["orders-pipeline"]        // remove to match every pipeline
  }
}

Watch forStage-level and action-level events have their own detail types (... Stage Execution State Change, ... Action Execution State Change).

High-severity GuardDuty finding

Use whenPaging on-call or starting automated containment.

{
  "source": ["aws.guardduty"],
  "detail-type": ["GuardDuty Finding"],
  "detail": {
    "severity": [{ "numeric": [">=", 7] }]    // high (7.0-8.9) and critical (9.0-10.0)
  }
}

Watch forIn a multi-account setup, create the rule in the GuardDuty administrator account, which receives every member's findings.

A resource became noncompliant in AWS Config

Use whenTriggering remediation or notifying the owner.

{
  "source": ["aws.config"],
  "detail-type": ["Config Rules Compliance Change"],
  "detail": {
    "configRuleName": ["restricted-ssh"],
    "newEvaluationResult": {
      "complianceType": ["NON_COMPLIANT"]
    }
  }
}

A specific API call, from CloudTrail

Use whenReacting within seconds to a sensitive change, such as opening a security group.

{
  "source": ["aws.ec2"],
  "detail-type": ["AWS API Call via CloudTrail"],
  "detail": {
    "eventSource": ["ec2.amazonaws.com"],
    "eventName": ["AuthorizeSecurityGroupIngress"]
  }
}

Watch forNeeds a CloudTrail trail. Events arrive only on the default bus in the Region of the call (us-east-1 for IAM). Read-only calls need the rule state ENABLED_WITH_ALL_CLOUDTRAIL_MANAGEMENT_EVENTS.

An exposed access key (AWS Health)

Use whenAutomatically deactivating keys AWS has found in public code.

{
  "source": ["aws.health"],
  "detail-type": ["AWS Health Event"],
  "detail": {
    "service": ["RISK"],
    "eventTypeCode": ["AWS_RISK_CREDENTIALS_EXPOSED"]
  }
}

Auto Scaling failed to launch an instance

Use whenAlerting on capacity, quota or launch template problems.

{
  "source": ["aws.autoscaling"],
  "detail-type": ["EC2 Instance Launch Unsuccessful"],
  "detail": {
    "AutoScalingGroupName": ["web-asg"]
  }
}

An ECS task stopped unexpectedly

Use whenCatching crashes and out-of-memory kills.

{
  "source": ["aws.ecs"],
  "detail-type": ["ECS Task State Change"],
  "detail": {
    "lastStatus": ["STOPPED"],
    "stopCode": [{ "anything-but": "UserInitiated" }],   // ignore deliberate stops
    "clusterArn": ["arn:aws:ecs:us-east-1:222222222222:cluster/prod"]
  }
}
