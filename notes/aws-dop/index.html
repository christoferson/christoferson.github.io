How to use this guide

Work through the domains in order of exam weight, then use the reference pages to review.

  1. Start with Domains 1 and 2SDLC automation and IaC carry 39% of the exam and underpin every other domain.
  2. Then cover 6, 3, 4 and 5Security, resilience, monitoring and incident response build on the same pipelines and templates.
  3. Review with the reference pagesUse the service cheat sheet and key comparisons to drill "which service or strategy fits" questions.
