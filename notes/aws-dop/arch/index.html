Multi-account CI/CD for a containerized service

A push to GitHub builds and scans an image in a tooling account, deploys it to staging, waits for approval, then runs a canary blue/green deployment to ECS in production with automatic rollback.

Serverless application with gradual deployments

An API Gateway, Lambda and DynamoDB service released through staging to production with a CodeDeploy canary, pre-traffic tests and automatic rollback on alarms.

Domain 1Domain 3Domain 4SAMCodeDeployLambda

Database changes with no downtime

An RDS for PostgreSQL major version upgrade through a blue/green switchover of about a minute, and schema changes shipped through the pipeline as backward-compatible migrations.

Domain 1Domain 3RDS Blue/GreenFlywaySecrets Manager

EKS platform with GitOps

Teams deploy to per-environment EKS clusters by merging to Git, with Argo CD syncing, Pod Identity roles per service, Karpenter scaling on Spot, central telemetry and routine upgrades.

Domain 1Domain 3Domain 6Amazon EKSArgo CDKarpenter

Container image scanning and deployment gate

Images are scanned in the build and again in ECR, any CRITICAL or HIGH finding stops the pipeline, and running images are rescanned with alerts when new CVEs appear.

Domain 1Domain 6Amazon ECRAmazon InspectorCodePipeline

Account vending with AWS Control Tower

A team requests an account and Control Tower Account Factory creates it in the right OU with logging, guardrails, the company baseline, team access and network ready, with no manual steps.

Domain 2Domain 6Control TowerAccount FactoryCfCT

Fleet patching and compliance across accounts

Hundreds of Linux and Windows instances across accounts are patched on schedule, critical CVEs are fixed automatically within days, compliance is proven centrally, and Auto Scaling groups get patched golden AMIs.

Domain 2Domain 6Domain 5Patch ManagerInspectorImage Builder

Multi-Region active/active web application

Two Regions serve traffic at the same time, with replicated data, latency routing and health checks, so losing a Region costs minutes of recovery and about a second of data.

Domain 3Domain 1Route 53DynamoDB global tablesARC

Organization-wide backup and recovery

Every account backs up tagged resources under one Organizations backup policy, with copies in a locked vault in a separate account and Region, automated restore tests and compliance reports.

Domain 3Domain 6Domain 2AWS BackupVault Lock

Organization-wide centralized logging

Audit, configuration, network and application logs from every account and Region land in a tamper-proof log archive, kept for seven years and searchable with Athena.

Domain 4Domain 6Domain 2CloudTrailData FirehoseObject Lock

Automated response to a compromised EC2 instance

A GuardDuty finding in any account starts a workflow that isolates the instance, preserves its disks, revokes its stolen credentials, replaces it and notifies on-call, within a minute.
