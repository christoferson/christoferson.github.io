Exam guide

AWS Certified DevOps Engineer – Professional (DOP-C02) exam guide

Version or dateThe HTML exam guide on docs.aws.amazon.com shows no version number, date or revision history. The older downloadable PDF is labeled "Version 1.6 DOP-C02" (file dated November 2024, modified February 2025).

Facts recorded75 questions (65 scored, 10 unscored), 180 minutes, passing score 750 of 1,000, compensatory scoring. Domains: SDLC Automation 22%, Configuration Management and IaC 17%, Resilient Cloud Solutions 15%, Monitoring and Logging 15%, Incident and Event Response 14%, Security and Compliance 17%.

NoteThe in-scope services list still uses old names (Kinesis Data Firehose, Fault Injection Simulator) and still lists retired or closed services (CodeStar, OpsWorks, Proton, Copilot, App2Container, CodeGuru). No out-of-scope list is published. The certification page says the Korean version retires after December 31, 2026.

Last checkedNovember 3, 2026.

Used onAll task pages, the cheat sheet and comparisons.
