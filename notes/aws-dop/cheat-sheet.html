Developer tools

ServiceWhat it's forKey DOP details
AWS CodePipelineOrchestrates release stages: source, build, test, approval, deployV2 pipelines: triggers with Git tag, branch and file-path filters, pipeline variables, stage conditions and rollback. Cross-account deploys use a role in the target account plus a customer managed KMS key on the artifact bucket. Cross-Region actions need an artifact bucket per Region.
AWS CodeBuildManaged build and test containers driven by buildspec.ymlPhases install, pre_build, build, post_build; reports for test results and coverage; caching (S3 or local); privileged mode to build Docker images; VPC access needs a NAT for the internet; batch builds; secrets from Parameter Store or Secrets Manager in env.
AWS CodeDeployDeploys to EC2/on-premises, Lambda and ECSIn-place or blue/green on EC2; canary, linear or all-at-once for Lambda and ECS; appspec.yml lifecycle hooks; automatic rollback on failure or CloudWatch alarm; needs the CodeDeploy agent on EC2.
AWS CodeCommit available againManaged Git repositoriesClosed to new customers in July 2024, then reopened. Triggers and EventBridge events on pushes and pull requests; approval rule templates.
AWS CodeConnections formerly CodeStar ConnectionsConnects pipelines and builds to GitHub, GitLab and BitbucketA connection starts PENDING and must be authorized in the console once. Also used by CloudFormation Git sync.
AWS CodeArtifactPrivate package repositories (npm, PyPI, Maven, NuGet, others)Upstream repositories and external connections to public registries; domains share storage across accounts; auth token valid up to 12 hours (aws codeartifact login).
AWS CodeStar retiredProject templates that wired the Code* services togetherDiscontinued July 2024. Use CodePipeline with CodeBuild and CodeDeploy, or CodeCatalyst.
Amazon CodeGuruReviewer: automated code review. Profiler: runtime performance profilingReviewer no new repositories since Nov 2025: use Amazon Q Developer or Inspector code security for new projects. Profiler finds the most expensive code paths in JVM and Python apps.
AWS Fault Injection Service formerly Fault Injection SimulatorControlled chaos experimentsExperiment templates with actions (stop instances, inject latency, throttle APIs, AZ power interruption scenario), targets selected by tag, and stop conditions on CloudWatch alarms.
AWS X-RayDistributed tracingTrace map, segments and subsegments, annotations (indexed, filterable) vs metadata (not indexed), sampling rules, X-Ray daemon or ADOT collector; active tracing on Lambda and API Gateway.
AWS CDKInfrastructure as code in TypeScript, Python, Java, C#, GoSynthesizes CloudFormation; constructs L1 (raw), L2 (defaults), L3 (patterns); cdk bootstrap per account and Region; cdk diff; CDK Pipelines for self-mutating pipelines.
AWS CLI, SDKs and ToolsScripted and programmatic accessNamed profiles, aws sso login, role assumption with source_profile; SDKs retry throttled calls with exponential backoff.
AWS CloudShellBrowser shell with the CLI preinstalled and the console user's credentialsPersistent 1 GB home directory per Region; can run inside a VPC.

Management and governance

ServiceWhat it's forKey DOP details
AWS CloudFormationDeclarative infrastructure as codeChange sets; stack policies; DeletionPolicy and UpdateReplacePolicy (Retain, Snapshot); CreationPolicy with cfn-signal; UpdatePolicy for Auto Scaling rolling or replacing updates; custom resources (Lambda must respond); nested stacks and exports; drift detection; rollback triggers; ContinueUpdateRollback; hooks; Git sync.
CloudFormation StackSetsOne template across many accounts and RegionsService-managed permissions with Organizations: target OUs, automatic deployment to new accounts. Concurrency and failure tolerance settings; drift detection across instances.
AWS Systems ManagerOperations hub for EC2, on-premises and hybrid nodesRun Command, State Manager (keep configuration in place), Automation runbooks (multi-account, multi-Region, approvals), Patch Manager (baselines, patch groups, patch policies), Session Manager (no SSH, logged), Parameter Store (standard and advanced tiers, no rotation), Inventory, Maintenance Windows, OpsCenter, Distributor, Change Manager. Needs the SSM Agent and an instance role.
AWS OpsWorks retiredManaged Chef and Puppet, and OpsWorks StacksEnd of life May 2024. Use Systems Manager (State Manager, Run Command, Automation).
Amazon CloudWatchMetrics, alarms, dashboardsStandard (1-minute) and high-resolution (1-second) metrics; metric math; anomaly detection; composite alarms to reduce noise; alarm actions (SNS, Auto Scaling, EC2, Systems Manager); cross-account observability; Synthetics canaries; RUM; Application Signals; Container and Lambda Insights; Contributor Insights.
Amazon CloudWatch LogsLog storage, search and processingRetention per log group (default never expires); Logs Insights queries; metric filters; subscription filters to Lambda, Kinesis, Data Firehose or cross-account destinations; KMS encryption; data protection policies; CloudWatch agent for OS and application logs; embedded metric format.
AWS CloudTrailAPI activity audit log90-day event history of management events; trails for longer retention, data events, Insights events and network activity events; organization trails; log file integrity validation; delivery to S3, CloudWatch Logs and EventBridge.
CloudTrail Lake closed to new customers May 2026SQL queries over an event data storeExisting customers only. New setups query trail logs in S3 with Athena.
AWS ConfigConfiguration history and complianceRecorder (continuous or daily); managed, custom Lambda and Guard rules; conformance packs; organization rules; aggregators with advanced SQL queries; remediation through Systems Manager Automation (automatic with retries).
AWS OrganizationsMulti-account managementOUs; SCPs (cap principals), RCPs (cap access to resources), declarative policies, tag, backup and AI opt-out policies; consolidated billing; delegated administrators; trusted access for services. SCPs don't affect the management account or service-linked roles.
AWS Control TowerGoverned multi-account landing zoneLog archive and audit accounts; Account Factory (and AFT for Terraform); preventive (SCP/RCP), detective (Config) and proactive (CloudFormation hook) controls; drift detection on the landing zone; Customizations for Control Tower.
AWS Service CatalogApproved products that users launch self-servicePortfolios shared across accounts and OUs; launch constraints (a role launches the product, so users don't need its permissions); template constraints; TagOptions.
AWS Proton retiredPlatform-team templates for environments and servicesEnd of support October 7, 2026; deployed infrastructure stays. Use CloudFormation or CDK templates shared through Service Catalog.
AWS Auto ScalingScaling plans across EC2, ECS, DynamoDB and AuroraApplication Auto Scaling handles ECS services, DynamoDB capacity, Aurora replicas, Lambda provisioned concurrency and more, with target tracking, step and scheduled policies.
AWS HealthEvents about AWS service issues and scheduled changes affecting your resourcesAccount-specific events (maintenance, retirements, AWS_RISK_CREDENTIALS_EXPOSED); organizational view; EventBridge rules on aws.health for automated response.
AWS Trusted AdvisorBest-practice checks: cost, performance, security, fault tolerance, service limitsFull checks need Business or Enterprise Support; results to EventBridge; organizational view; service quota checks.
AWS Resilience HubAssesses applications against RTO and RPO targetsResiliency policies; assessments with recommendations (alarms, SOPs, FIS experiments); can run in a pipeline to catch resilience regressions.
AWS Compute OptimizerRight-sizing recommendationsEC2, Auto Scaling groups, EBS, Lambda, ECS on Fargate, RDS; based on CloudWatch history (enhanced metrics for longer lookback).
AWS License ManagerTracks and enforces software license usageLicense configurations attached to AMIs or launch templates; hard limits block launches beyond your license count.
Amazon Managed GrafanaManaged Grafana dashboardsData sources: CloudWatch, Managed Prometheus, X-Ray, OpenSearch, Athena; IAM Identity Center sign-in.
Amazon Managed Service for PrometheusManaged Prometheus-compatible metricsFor EKS and container metrics with PromQL; collectors (agentless scraper or ADOT); alert manager rules.

Compute

ServiceWhat it's forKey DOP details
Amazon EC2Virtual serversLaunch templates (versions); instance profiles; IMDSv2; user data; placement groups; EC2 status checks with auto recovery; Capacity Reservations for DR.
Amazon EC2 Auto ScalingKeeps the right number of healthy instancesTarget tracking, step, scheduled and predictive scaling; ELB health checks; lifecycle hooks; warm pools; instance refresh (with checkpoints and rollback); mixed instances and Spot; suspended processes; capacity rebalancing.
EC2 Image BuilderAutomated AMI and container image pipelinesRecipes (base image + components), infrastructure configuration, distribution to accounts and Regions, scheduled rebuilds, built-in tests; output AMI IDs to Parameter Store for launch templates.
AWS Elastic BeanstalkManaged platform for web appsDeployment policies: all at once, rolling, rolling with additional batch, immutable, traffic splitting; blue/green by swapping environment URLs (CNAME swap); .ebextensions and platform hooks; saved configurations.
AWS App RunnerFully managed containers or source-code web servicesAutomatic deployments from ECR or a repository; auto scaling by concurrency; VPC connector for private resources.
AWS Serverless Application RepositoryShares SAM applicationsPublish privately, to specific accounts or publicly; deploy nested applications with AWS::Serverless::Application.

Containers

ServiceWhat it's forKey DOP details
Amazon ECSAWS-native container orchestrationTask definitions (task role vs task execution role); services with rolling deployments plus the deployment circuit breaker with rollback; built-in blue/green and CodeDeploy blue/green; capacity providers; Service Connect; ECS Exec; stopped reasons and exit codes (137 = out of memory).
AWS FargateServerless compute for ECS and EKSNo instances to patch; sized per task; Fargate Spot for interruptible work; ephemeral storage.
Amazon EKSManaged KubernetesManaged node groups, Fargate profiles, Karpenter or Cluster Autoscaler; EKS Pod Identity or IRSA; access entries; add-ons; control plane logs (off by default); upgrade one minor version at a time; Container Insights.
Amazon ECRContainer image registryImage scanning (basic or Inspector enhanced, continuous); lifecycle policies; tag immutability; cross-account and cross-Region replication; pull-through cache; repository policies.
Amazon EKS DistroThe Kubernetes distribution EKS uses, to run yourselfConsistent Kubernetes on premises or elsewhere; EKS Anywhere adds tooling and support.
Red Hat OpenShift Service on AWS (ROSA)Managed OpenShift, jointly supported by Red Hat and AWSFor teams already standardized on OpenShift.
AWS Copilot end of support June 2026CLI that generated ECS and App Runner infrastructure and pipelinesNo more updates or support after June 12, 2026. Use CDK or CloudFormation.
AWS App2Container closed to new customersContainerizes existing Java and .NET applications without source codeClosed to new customers November 7, 2025; AWS Transform is the suggested alternative.

Serverless and application integration

ServiceWhat it's forKey DOP details
AWS LambdaEvent-driven functionsVersions and aliases with weighted traffic; CodeDeploy canary or linear shifts with alarm rollback; reserved vs provisioned concurrency; destinations and DLQs for async failures; event source mappings (batch size, partial batch response); layers; container images; SnapStart.
AWS SAMServerless shorthand for CloudFormationTransform: AWS::Serverless-2016-10-31; AutoPublishAlias and DeploymentPreference (canary, linear, hooks, alarms); sam build, sam deploy, sam local, sam sync, sam pipeline.
AWS Step FunctionsWorkflow orchestrationStandard (long, exactly once) vs Express (high volume, short); retries with backoff and catch; .waitForTaskToken for human approval; SDK integrations call AWS APIs directly; Distributed Map.
Amazon EventBridgeEvent bus and routingRules with event patterns; default bus receives AWS service and CloudTrail events; cross-account and cross-Region buses; archive and replay; Scheduler; Pipes; input transformers; retry policy and DLQ on targets.
Amazon SNSPub/sub notificationsFan-out to SQS, Lambda, HTTP, email, SMS; subscription filter policies; FIFO topics; KMS encryption (key policy must allow publishing services).
Amazon SQSMessage queues for decouplingStandard vs FIFO; visibility timeout; dead-letter queues and redrive; long polling; scale consumers on ApproximateNumberOfMessagesVisible or backlog per instance.
Amazon AppFlowManaged data flows between SaaS apps (Salesforce, ServiceNow, Slack) and AWSScheduled, event-triggered or on-demand flows into S3 or Redshift, with filtering and encryption.

Networking and content delivery

ServiceWhat it's forKey DOP details
Amazon VPCIsolated networksSecurity groups (stateful) vs network ACLs (stateless, deny rules); gateway and interface endpoints; Flow Logs; Reachability Analyzer; IPAM; shared subnets through RAM.
Elastic Load BalancingALB (layer 7), NLB (layer 4), Gateway Load Balancer (appliances)Health checks; weighted target groups for blue/green and canary; connection draining (deregistration delay); cross-zone load balancing; access logs to S3; ALB mTLS; zonal shift.
Amazon Route 53DNS and health checksRouting policies: simple, weighted, latency, failover, geolocation, geoproximity, multivalue, IP-based; health checks (including on CloudWatch alarms); Application Recovery Controller for routing controls and readiness checks.
Amazon CloudFrontCDN and edgeOrigin failover with origin groups; cache invalidations; continuous deployment (staging distribution); Lambda@Edge and CloudFront Functions; WAF and Shield at the edge; ACM certificate in us-east-1.
Amazon API GatewayManaged APIs (REST, HTTP, WebSocket)Stages and stage variables; canary release deployments; throttling and usage plans; execution and access logs; X-Ray tracing; WAF on REST APIs.
AWS Transit GatewayHub that connects many VPCs and on-premises networksRoute tables for segmentation; centralized inspection and egress VPCs; inter-Region peering; share across accounts with RAM.
AWS PrivateLinkPrivate access to services through interface endpointsExpose your own service behind an NLB as an endpoint service; endpoint policies; avoids internet and NAT.
AWS Site-to-Site VPNIPsec tunnels to on premisesTwo tunnels per connection for redundancy; often the backup for Direct Connect.
AWS Client VPNManaged remote-access VPN for usersAuthentication with certificates, Active Directory or SAML; authorization rules per network.

Security, identity and compliance

ServiceWhat it's forKey DOP details
AWS IAMIdentities and permissionsRoles over users; identity, resource, boundary, session policies; explicit deny wins; permissions boundaries for delegation; Access Analyzer (external, unused, policy generation, validation, custom checks); iam:PassRole.
AWS IAM Identity CenterWorkforce single sign-on across accountsIdentity source (built-in, AD, external IdP with SCIM); permission sets; assignments to groups and accounts; attributes for ABAC; aws sso login.
AWS STSTemporary credentialsAssumeRole, AssumeRoleWithSAML, AssumeRoleWithWebIdentity, GetSessionToken (MFA); sessions 1 to 12 hours, 1 hour when chaining; external ID for third parties; revoke sessions by token issue time.
Amazon CognitoSign-in for application usersUser pools (authentication, tokens) and identity pools (temporary AWS credentials for app users).
AWS Directory ServiceManaged Microsoft AD, AD Connector, Simple ADIdentity source for Identity Center; domain join for EC2 and FSx for Windows; trusts with on-premises AD.
AWS Resource Access ManagerShares resources across accountsSubnets, Transit Gateways, Route 53 Resolver rules, License Manager configurations, Private CA; share with the whole organization or OUs.
AWS KMSEncryption keysAWS owned, AWS managed (can't share across accounts) and customer managed keys; key policies and grants; automatic and on-demand rotation; multi-Region keys; custom key stores (CloudHSM, external).
AWS CloudHSMSingle-tenant hardware security modules in your VPCExclusive key control; run at least two HSMs across AZs; PKCS#11, JCE and OpenSSL; KMS custom key store.
AWS Certificate ManagerPublic and private TLS certificatesFree public certificates; DNS validation auto-renews, imported certificates don't; expiry events to EventBridge; Config rule acm-certificate-expiration-check; Regional (CloudFront needs us-east-1).
AWS Secrets ManagerStores and rotates secretsRotation with Lambda (createSecret, setSecret, testSecret, finishSecret); managed rotation for RDS; single or alternating users; cross-Region replication; resource policies for cross-account access.
Amazon GuardDutyThreat detectionAnalyzes CloudTrail, VPC Flow Logs and DNS logs without you enabling them; protection plans (S3, EKS, Runtime, Malware, RDS, Lambda); Extended Threat Detection; delegated admin; findings to EventBridge; severity 7+ = high.
Amazon InspectorVulnerability scanningEC2 (agent or agentless), ECR images (continuous), Lambda; network reachability; CIS scans; SBOM export. Inspector Classic superseded.
Amazon DetectiveInvestigation of security findingsBehavior graphs from CloudTrail, Flow Logs, GuardDuty and EKS audit logs; shows scope and root cause of a finding.
Amazon MacieSensitive data discovery in S3Automated discovery (sampling) or jobs; managed and custom data identifiers; allow lists; S3 only.
AWS Security Hub CSPM formerly Security HubSecurity posture checks and finding aggregationStandards (FSBP, CIS, PCI DSS, NIST); needs AWS Config; central configuration policies; cross-Region aggregation; ASFF findings; automation rules; custom actions to EventBridge.
AWS WAFLayer 7 web filteringWeb ACLs on CloudFront, ALB, API Gateway REST, AppSync, Cognito, App Runner; managed rule groups; rate-based rules; Count mode to test; logs to aws-waf-logs-*.
AWS ShieldDDoS protectionStandard: free, layer 3 and 4. Advanced: SRT support, cost protection, automatic layer 7 mitigation, health-based detection.
AWS Network FirewallManaged stateful VPC firewallStateless and stateful (Suricata) rule groups; domain allow lists; TLS inspection; central inspection VPC with Transit Gateway.

Storage

ServiceWhat it's forKey DOP details
Amazon S3Object storageVersioning; Same-Region and Cross-Region Replication (with Replication Time Control); lifecycle rules; Object Lock (governance or compliance); Block Public Access; default encryption; event notifications and EventBridge; Batch Operations; Storage Lens.
S3 Glacier storage classesArchival classes inside S3Instant Retrieval, Flexible Retrieval, Deep Archive; reached through lifecycle transitions.
Amazon S3 Glacier (vaults) closed to new customersThe original standalone archive service with vaultsExisting customers only; use the S3 Glacier storage classes instead.
Amazon EBSBlock storage for EC2Snapshots (incremental, copy across Regions and accounts); Data Lifecycle Manager; encryption by default per Region; Fast Snapshot Restore; zonal (a volume is in one AZ).
Amazon EFSShared NFS file system across AZsRegional or One Zone; replication to another Region; access points; lifecycle to Infrequent Access.
Amazon FSx (Windows File Server, Lustre, NetApp ONTAP, OpenZFS)Managed specialized file systemsWindows: SMB and AD, Multi-AZ. Lustre: high-performance compute, links to S3. ONTAP: multiprotocol, SnapMirror replication. OpenZFS: NFS with snapshots and clones.
AWS BackupCentralized backup across servicesBackup plans and rules; selection by tag; cross-Region and cross-account copies; organization backup policies; Vault Lock; restore testing; audit with Backup Audit Manager.
AWS Elastic Disaster RecoveryContinuous block-level replication of servers for DRLow-cost staging area; launches recovery instances in minutes (RPO seconds, RTO minutes); drills without disruption; failback.
AWS Storage GatewayHybrid storage between on premises and AWSS3 File Gateway, FSx File Gateway, Volume Gateway (cached or stored, EBS snapshots), Tape Gateway.

Database

ServiceWhat it's forKey DOP details
Amazon RDSManaged relational databasesMulti-AZ instance (standby) vs Multi-AZ cluster (two readable standbys); read replicas (cross-Region, promotable); automated backups and point-in-time restore; blue/green deployments for upgrades; RDS Proxy; IAM authentication; encrypt existing DB by snapshot copy.
Amazon AuroraCloud-native MySQL and PostgreSQLSix copies across three AZs; up to 15 replicas with fast failover; Global Database (cross-Region replication typically under a second, managed failover); Backtrack (MySQL); cloning; auto scaling replicas.
Aurora Serverless v2Aurora with capacity that scales in fine incrementsSet minimum and maximum ACUs; mix with provisioned instances in one cluster; can scale to zero when configured.
Amazon DynamoDBKey-value and document NoSQLOn-demand or provisioned with auto scaling; global tables (multi-Region active-active); point-in-time recovery; Streams for event processing; TTL; DAX caching.
Amazon ElastiCacheIn-memory cache (Valkey, Redis OSS, Memcached)Multi-AZ with automatic failover; Global Datastore for cross-Region; serverless option.
Amazon MemoryDBDurable in-memory database (Valkey, Redis OSS compatible)Multi-AZ transaction log for durability; use as a primary database, not just a cache.
Amazon DocumentDBMongoDB-compatible document databaseCluster storage across three AZs; replicas; global clusters.
Amazon RedshiftData warehouseProvisioned or Serverless; automated snapshots, cross-Region snapshot copy; Multi-AZ for RA3.
AWS DMSDatabase migration and replicationFull load plus change data capture (CDC); homogeneous or heterogeneous (with Schema Conversion); also used for continuous replication to another Region or engine.

Analytics

ServiceWhat it's forKey DOP details
Amazon AthenaServerless SQL over data in S3Query CloudTrail, ALB, VPC Flow and WAF logs; partition projection; workgroups for cost limits; results in S3.
Amazon Kinesis Data StreamsReal-time data streamsShards or on-demand capacity; retention 24 hours to 365 days; consumers with enhanced fan-out; CloudWatch Logs subscription target.
Amazon Data Firehose formerly Kinesis Data FirehoseDelivers streaming data to destinationsTo S3, Redshift, OpenSearch, Splunk and HTTP endpoints; buffering by size and time; Lambda transformation; format conversion to Parquet; a common target for centralized logs.
Amazon OpenSearch ServiceSearch and log analyticsDashboards for logs; Multi-AZ with standby; ingestion pipelines; fine-grained access control; serverless collections.
Amazon EMRManaged Spark, Hadoop and other big data frameworksOn EC2, EKS or Serverless; managed scaling; Spot for task nodes.
Amazon Quick SightBusiness intelligence dashboardsDashboards over Athena, Redshift and other sources, for example cost or compliance reporting.
