The exam

SAP-C03 at a glance
Version
SAP-C03 replaces SAP-C02: the last C02 day is November 16, 2026 and C03 is delivered from November 17, 2026, with no beta. The guide has no version number.
Format
75 questions: 65 scored and 10 unscored (not identified); multiple choice and multiple response. 180 minutes.
Scoring
Scaled 100 to 1,000; pass at 720. Scoring is compensatory: you need to pass overall, not each domain.
Cost, languages, validity
300 USD; English, Japanese, Korean, Portuguese (Brazil), Simplified Chinese and Spanish (Latin America); valid for three years. Pearson VUE test center or online.
Candidate
Two or more years of experience using AWS services to design and implement cloud solutions.
Domains
1 Architecture design and implementation built for the cloud 25% · 2 Security, compliance, and governance 25% · 3 Cost-optimized architecture design 15% · 4 Resilience, migration, and business continuity 15% · 5 Operational excellence and automation 20% · 21 tasks, 115 skills

Domain 1: Architecture design built for the cloud

Architectures built for the cloud (Task 1.1)

ClueAnswer
Strict ordering per customer, no duplicatesSQS FIFO with a message group ID per customer and deduplication IDs (messaging)
FIFO queue processes one message at a timeA single message group ID for everything; spread the group IDs
Long-running workflow with waits and approvalsStep Functions Standard, or Lambda durable functions (December 2025) (workflows)
Deliver events straight to another account's bus or targetEventBridge direct cross-account targets (cross-account events)
Containers with least overhead, no KubernetesECS on Fargate; Kubernetes with managed nodes is EKS Auto Mode; GPUs without managing EC2 is ECS Managed Instances (containers)
Service mesh for ECS or EKS in a new designECS Service Connect or VPC Lattice (App Mesh is past end of support) (service networking)
Authenticate users at the load balancerALB authenticate-cognito or authenticate-oidc on an HTTPS listener (ingress)
One distribution for many tenant domainsCloudFront SaaS Manager (multi-tenant distributions) (edge)
Tenants may only read their own DynamoDB itemsdynamodb:LeadingKeys condition with the tenant ID, plus a Null check; never grant Scan (tenancy)

AI and ML in architectures (Task 1.2)

ClueAnswer
Every account calls Bedrock in a shared accountRole assumption or a gateway; Bedrock has no invocation resource policy (multi-account GenAI)
Central account hits tokens-per-minute limitsAll callers share its quotas; spread Bedrock across workload accounts or use cross-Region inference
New agent with tools, memory and identityBedrock AgentCore (Bedrock Agents is Agents Classic, closed to new customers) (agents)
Several units use one model, billed separatelyOne endpoint behind API Gateway with usage plans; separate copies come from a model package group shared with RAM (inference)
Multi-tenant RAGOne knowledge base with a mandatory tenant metadata filter applied by the server (RAG)

Hybrid cloud integration (Task 1.3)

ClueAnswer
Highest Direct Connect resiliency (99.99%)Two locations with two connections each (connectivity)
Private IP VPN over Direct ConnectThrough a Transit Gateway only
Copy file shares to AWS on a schedule with verificationDataSync (schedule at most hourly; Enhanced mode for scale) (data sync)
Resolve on-premises names from every VPC in the organizationRoute 53 Resolver outbound endpoint and forwarding rules shared with RAM (hybrid DNS)
Run EKS pods on on-premises serversEKS Hybrid Nodes; Outposts for AWS infrastructure on premises (hybrid compute)

Network architectures (Task 1.4)

ClueAnswer
Expose a service to consumers in another Region privatelyCross-Region PrivateLink (endpoint service with supported Regions) (multi-VPC)
No overlapping CIDRs across hundreds of accountsIPAM pools shared with RAM plus an SCP requiring them (IPAM)

IPv6-only workloads reach IPv4 servicesDNS64 with NAT64 on the NAT gateway (IPv6)

Data, storage, and databases (Task 1.5)

ClueAnswer
Managed Iceberg tables with compactionS3 Tables (lakehouse)
Active-active relational database across RegionsAurora DSQL (choosing a database)
Zero RPO across Regions for key-value dataDynamoDB global tables with multi-Region strong consistency (exactly 3 Regions) (high availability)

Windows and Linux clients share the same filesFSx for NetApp ONTAP (multi-protocol) (storage)

Domain 2: Security, compliance, and governance

Identity (Task 2.1)

ClueAnswer
Workforce access to many accountsIAM Identity Center with SAML and SCIM; direct IAM federation only for small or machine cases or encrypted assertions (federation)
Services must authorize the actual user, not a roleTrusted identity propagation (OAuth apps only)
Partner system calls the API with scoped tokensCognito resource server scopes and a confidential app client (client credentials or GetClientToken) (app auth)
Pods need AWS credentials, also in another accountEKS Pod Identity with a target role; IRSA only for Fargate, Windows, Outposts, EKS Anywhere
Vendor assumes a role in your accountTrust policy with an external ID (least privilege)
Show who really acted after several role hopsSource identity (set once, persists through role chaining)
No principal outside the organization reaches your bucketsRCP with aws:PrincipalOrgID and a service-principal exception (perimeters)
Corporate app access without VPN, with device postureAWS Verified Access (HTTP(S) and TCP)
On-premises servers need AWS credentials without keysIAM Roles Anywhere with certificates; OIDC federation for platforms that issue tokens (workload identity)

Encryption and keys (Task 2.2)

ClueAnswer
Share encrypted data across accountsCustomer managed key (AWS managed keys can't be used cross-account) (at rest)
Limit a key to use through one service and one bucketkms:ViaService and kms:EncryptionContext conditions
Certificates valid a few days for internal servicesAWS Private CA short-lived mode (ACM can't issue from it) (in transit)
Regulation requires a single-tenant HSM you alone controlCloudHSM (FIPS 140-3 Level 3 alone isn't the reason: KMS has it too) (HSMs)
Protect against harvest-now-decrypt-laterHybrid ML-KEM TLS: updated clients and PQ policies on load balancers and APIs (post-quantum)
Long-lived signatures must stay trustworthyML-DSA signing keys in KMS

Multi-account governance (Task 2.3)

ClueAnswer

Stop outside principals vs stop your principalsRCP on resources vs SCP on principals; neither affects the management account (SCPs and RCPs)

Turn on scanning in every account and RegionOrganizations Inspector policy; patch with Patch Manager patch policies (scanning)

Data transfer and network costs (Task 3.2)

ClueAnswer

Peak Bedrock capacity, lowest costCross-Region inference (source-Region price, no routing fee) (AI transfer)

ClueAnswer
Discover servers and dependencies, build a business caseAWS Transform discovery and assessment (Discovery Service and Migration Hub are closed to new customers) (discovery)

Oracle to Aurora PostgreSQL with minimal downtimeDMS Schema Conversion, then DMS full load plus CDC (data)

Disaster recovery (Task 4.2)

ClueAnswer
Data current, compute starts after the disasterPilot light; takes traffic at once at reduced size is warm standby (strategy)
Replicate whole servers with second-level RPOElastic Disaster Recovery (replication)
Assess whether the architecture meets RTO and RPOResilience Hub policy and assessment (procedures)
Orchestrate database, compute and traffic failover between two RegionsARC Region switch (failover)
See what happens when cross-Region replication stopsFIS Cross-Region: Connectivity scenario (testing)
Back up EKS cluster state and volumesAWS Backup for EKS, plus ECR replication for images (containers)

Business continuity and resiliency (Task 4.3)

ClueAnswer
Same backup rules in every accountOrganizations backup policies by tag, copies to a central backup account (governance)
Measure how long customers are affectedFIS experiment plus Synthetics canaries (failover tests)
Survive an AZ loss without launching anythingStatic stability: about 50% spare across three AZs (resilient design)
A compromised admin must not delete backupsCompliance-mode Vault Lock or a logically air-gapped vault (ransomware)
Stop all experiments nowFIS safety lever (chaos engineering)

Numbers worth knowing

Design and security (Domains 1 and 2)
Message sizes
SQS and SNS 1 MiB; Kinesis 10 MiB; EventBridge 1 MB (Task 1.1)
Direct Connect
Maximum resiliency 99.99% (two locations, two connections each); high 99.9% (Task 1.3)
DynamoDB multi-Region strong consistency
Exactly 3 Regions (Task 1.5)
Identity Center
3,500 permission sets; 7,000 accounts and 7,000 applications; SCIM token valid 1 year (Task 2.1)
RCPs and SCPs
RCPs 5 per target and 5,120 characters; SCPs 10 per target and 10,240 characters (Tasks 2.1, 2.3)
KMS
Rotation 90–2,560 days; up to 25 on-demand rotations; symmetric quota 10,000–100,000 requests per second, charged to the caller (Task 2.2)
Role chaining
1 hour (Task 2.1)
Cost (Domain 3, us-east-1)
Commitments
Compute Savings Plans up to 66%; EC2 Instance Savings Plans 72%; Database Savings Plans 35%; Spot up to 90% (Task 3.1)
Bedrock tiers
Priority 75% premium; Flex and batch 50% off (Task 3.1)
Transfer
Cross-AZ US$0.01 per GB each way; NAT processing US$0.045 per GB; Transit Gateway US$0.02 per GB; PrivateLink US$0.01 per GB (Task 3.2)
CloudWatch Logs
Ingestion US$0.50 (Standard) or US$0.25 (Essentials) per GB; storage US$0.03 per GB-month; custom metrics US$0.30 each (Task 3.4)
Resilience and operations (Domains 4 and 5)
Transform MGN
2,160 free replication hours per server; TCP 1500 data, 443 control (Task 4.1)
Elastic Disaster Recovery
US$0.028 per server-hour; 300 replicating servers per account and Region (not adjustable) (Task 4.2)
ARC
Region switch US$70 per plan per month, exactly 2 Regions; routing control US$2.50 per cluster-hour (Task 4.2)
Vault Lock
Compliance-mode grace time at least 3 days (Task 4.3)
FIS
US$0.10 per action-minute; up to 5 stop conditions (Tasks 4.2, 4.3)

Up to 5 delegated administrators (Task 5.1)
Predictive scaling

0–2 retries; events kept up to 6 hours (Task 5.4)
