How to use this page

Read each list from the top: posts are newest first, and a newer post on the same design usually replaces an older one. A note saying a post predates a feature means it describes an older approach; the design still works, but the current answer may use the newer feature. The posts come from the AWS Architecture, Migration and Modernization, Database, Big Data, Machine Learning, Compute and Cloud Financial Management blogs, and the dates are publication dates.

Several services changed around the time the SAP-C03 guide was published, such as AWS Application Migration Service becoming AWS Transform MGN and Migration Hub closing to new customers, so older posts use older names. The AWS services page lists the status changes.
