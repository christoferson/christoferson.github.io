Overview

The exam guide lists about 85 services in fourteen categories and says the list is non-exhaustive and subject to change. Many skills name features rather than services (SageMaker Feature Store, Model Registry, Bedrock knowledge bases, Guardrails, AgentCore Observability); those are listed under features the notes rely on.

Each entry says what the service is for on this exam and links to the task sections that explain it. Background means the notes only mention it, or not at all: know in one sentence what it does. The cheat sheet maps question clues to services, and the comparisons page sets similar options side by side.

Machine learning and AI

  • Amazon SageMaker AI: the core of the exam: data preparation (Canvas, Data Wrangler, Processing, Feature Store), training (built-in algorithms, script mode, tuning, HyperPod), deployment (real-time, serverless, asynchronous, batch, inference components), MLOps (Pipelines, Model Registry, MLflow) and monitoring. 1.2, 2.2, 3.1, 3.3, 4.1
  • Amazon Bedrock: serverless foundation models, model choice and service tiers, fine-tuning and distillation, knowledge bases, Guardrails, evaluations, Prompt Management, Custom Model Import, API keys. 2.1, 2.2, 2.3, 3.1, 4.3
  • Amazon Bedrock AgentCore: Runtime, Gateway, Memory, Identity, Policy, Observability and Evaluations for deploying and running agents. 3.1, 3.2, 3.3, 4.1, 4.2
  • Amazon Comprehend: entities, sentiment, language, PII detection and redaction, toxicity, custom classification. 1.2, 1.3, 2.1
  • Amazon Comprehend Medical: medical entities and protected health information in clinical text. 2.1
  • Amazon Rekognition: image labels, moderation, faces, Custom Labels; image attributes for bias checks and unsafe-image screening. 2.1, 1.3, 1.3
  • Amazon Textract: text, forms, tables, queries, invoices and IDs from documents. 2.1, 1.1
  • Amazon Transcribe: speech to text, custom vocabularies, PII redaction, Call Analytics. 2.1, 1.1
  • Amazon Translate: translation with custom terminology; back-translation for text augmentation. 2.1, 1.2
  • Amazon Lex, Amazon Polly and Amazon Personalize: chatbots, text to speech and recommendations as ready-made AI services. 2.1
  • Amazon CodeGuru: code quality and security review in pipelines; Reviewer takes no new repository associations and CodeGuru Security is no longer documented, so new pipelines use Amazon Inspector and Amazon Q code reviews. 4.3
  • Amazon DevOps Guru (background): ML-based detection of operational anomalies in applications.
  • AWS HealthLake (background): storing and analysing health data in FHIR format.

Analytics

  • AWS Glue: serverless Spark ETL, the Data Catalog, streaming jobs, Detect PII, FindMatches for fuzzy duplicates. 1.2, 1.1, 1.3
  • AWS Glue DataBrew: no-code cleaning recipes, profile jobs and rulesets. 1.2, 1.3, 1.3
  • AWS Glue Data Quality: DQDL rules, rule recommendations, row-level quarantine, anomaly detection. 1.3, 4.1
  • Amazon Athena: SQL over S3 data, unloading query results for training. 1.1, 1.1
  • Amazon EMR: large custom Spark jobs, including EMR Serverless. 1.2, 1.1
  • Amazon Kinesis (Data Streams) and Amazon Data Firehose: streaming ingestion, with Firehose landing data in S3 in Parquet. 1.1, 1.2
  • Amazon Managed Service for Apache Flink: stateful stream processing with long windows and joins. 1.1, 1.2
  • Amazon OpenSearch Service: vector store with hybrid search for RAG, serverless or managed. 1.1, 2.2, 4.2
  • Amazon Redshift: warehouse data for training, and structured knowledge bases that turn questions into SQL. 1.1, 2.1
  • AWS Lake Formation: fine-grained data lake permissions; record matching (FindMatches). 1.3
  • Amazon Quick (background): AWS's business intelligence and agent workspace; the alternative AWS names for Amazon Q Business. 2.1

Application integration

  • Amazon EventBridge: pipeline triggers, approval and failure events, schedules for retraining and knowledge base syncs. 3.3, 4.1, 3.2
  • AWS Step Functions: general workflows across services, polling loops, human approval with task tokens. 3.1, 2.3, 3.3
  • Amazon MWAA: managed Apache Airflow for teams that already orchestrate in Airflow. 3.1
  • Amazon SNS: alarm, pipeline and asynchronous inference notifications. 4.1, 3.1
  • Amazon SQS: queuing changes for knowledge base syncs and decoupling work. 3.3

Cloud financial management

  • AWS Budgets: cost and usage alerts and budget actions (IAM policy or SCP). 4.2
  • AWS Cost Explorer and AWS Billing and Cost Management: cost analysis by service, tag and Bedrock model; cost allocation tags, Cost Anomaly Detection and data exports. 4.2

Compute and containers

  • AWS Lambda: stream transforms, triggers, small CPU models, tools for agents, remediation. 1.2, 3.1, 3.2
  • Amazon EC2: instance families for training and inference, Deep Learning AMIs, Spot, Capacity Blocks for self-managed work. 3.1, 4.2
  • Amazon EKS and Amazon ECS: self-managed model serving (vLLM, SGLang), GPU node pools, HyperPod on EKS. 3.1, 3.2
  • Amazon ECR: container images for training, inference and agents; immutable tags, scanning, lifecycle and repository policies. 3.2, 4.3
  • AWS Batch (background): queued batch compute jobs, an alternative to SageMaker batch transform for custom batch work.

Database

  • Amazon RDS (and Aurora PostgreSQL with pgvector): source data for training and a vector store for RAG. 1.1, 1.1
  • Amazon DynamoDB: source data exports, low-latency features and agent state. 1.1, 3.2
  • Amazon Neptune: graph data and GraphRAG through Neptune Analytics. 1.1, 2.1
  • Amazon DocumentDB and Amazon ElastiCache: vector search options, and ElastiCache as a semantic cache. 1.1, 3.2

Developer tools

  • AWS CodePipeline: V2 pipelines with triggers, variables, stage conditions and stage rollback. 3.3
  • AWS CodeBuild: tests, image builds, Inspector scans and test reports. 3.3, 3.2, 4.3
  • AWS CodeDeploy: canary and linear deployments for Lambda and ECS model servers. 3.3
  • AWS CodeCommit and AWS CodeConnections: Git repositories in AWS, or links to GitHub, GitLab, Bitbucket and Azure DevOps. 3.3
  • AWS CDK: infrastructure as code for SageMaker, Bedrock and AgentCore resources. 3.2, 3.2
  • AWS X-Ray: request tracing, now viewed in CloudWatch and fed by OpenTelemetry. 4.2
  • AWS CodeArtifact (background): private package repositories, useful when training or build hosts can't reach the public internet.

Management and governance

  • Amazon CloudWatch: metrics, logs, alarms, dashboards, generative AI observability, anomaly detection. 4.1, 4.2, 2.3
  • AWS CloudTrail: API audit; SageMaker endpoint invocations as data events. 4.3
  • AWS Config: configuration history and managed rules for SageMaker and Bedrock. 4.3
  • AWS CloudFormation: SageMaker, Bedrock and AgentCore resources as code, cross-stack references. 3.2, 3.3
  • AWS Auto Scaling (Application Auto Scaling): endpoint, inference component and serverless scaling. 3.2, 4.2
  • AWS Organizations: SCPs for model, region, API key and data retention controls; organization-level guardrails. 4.3, 4.3
  • AWS Systems Manager: Parameter Store for model locations and prompt version ARNs. 3.2
  • AWS Service Catalog: the products behind SageMaker Projects templates. 2.1
  • AWS Compute Optimizer: idle SageMaker endpoint recommendations. 4.2
  • AWS Trusted Advisor (background): account checks for cost, security, limits and fault tolerance.

Networking and content delivery

  • Amazon VPC: private subnets, security groups, gateway and interface endpoints, flow logs for ML workloads. 3.2, 4.3
  • Amazon API Gateway: a front door for models behind Lambda, with tracing. 4.2
  • Amazon CloudFront and AWS Direct Connect (background): content delivery at the edge, and private connections from on-premises networks.

Security, identity and compliance

  • IAM: execution roles, PassRole, condition keys, Bedrock model and guardrail conditions. 4.3, 4.3
  • AWS KMS: customer managed keys for volumes, artifacts, endpoints, Feature Store and Bedrock resources. 4.3
  • Amazon Inspector: image, SBOM and code scanning in CI/CD. 4.3, 3.2
  • Amazon Macie: finding personal data in S3 before it reaches training sets or knowledge bases. 1.2, 4.3
  • AWS Secrets Manager: credentials for data sources and builds instead of keys in code. 1.2, 4.3

Storage, media and transfer

  • Amazon S3: training data, model artifacts, data capture, S3 Vectors, checksums. 1.1, 1.1, 4.2
  • Amazon FSx (for Lustre) and Amazon EFS: fast shared file systems for training input. 1.1, 2.2
  • Amazon EBS: instance storage volumes, encrypted with your key. 1.1
  • Amazon S3 Glacier, AWS Storage Gateway, AWS DataSync and Amazon Kinesis Video Streams (background): archive storage classes, hybrid access to S3, bulk data transfer into AWS, and ingesting video streams.

  • CloudWatch generative AI observability and AgentCore Observability. 4.1, 4.1

Also used in these notes

Not on the in-scope list (some are on the out-of-scope list), but the notes mention them because questions use them to deliver an outcome:

  • Amazon S3 Vectors: low-cost vector storage for large, rarely queried indexes. 1.1, 4.2
  • Amazon GuardDuty (out of scope): AI Protection findings on Bedrock, AgentCore and SageMaker AI activity. 4.3
  • AWS IoT Greengrass (out of scope) and SageMaker Neo: running compiled models on edge devices. 3.1
  • Amazon Cognito (out of scope): sign-in for labeling and human evaluation work teams. 1.3, 2.3
  • Amazon Q Developer: code reviews, the alternative AWS names to CodeGuru. 4.3
  • Strands Agents (AWS open-source SDK): agent code, multi-agent patterns, hooks and conversation managers. 3.1, 4.1, 4.2

Status changes

Services and features, in scope or close to it, that have closed, ended or changed. A question may still describe the old option; know what replaced it.

Closed to new customers (existing customers continue)

  • SageMaker Clarify, Model Monitor, Debugger, Ground Truth, Augmented AI (A2I) and Role Manager: 30 July 2026. AWS points to open-source SHAP and Evidently with MLflow, TensorBoard and CloudWatch; Ground Truth Plus ended on 30 June 2026. 1.3, 2.3, 4.3
  • Amazon Kendra, Amazon Q Business and Bedrock Agents (now Agents Classic): 30 July 2026; use Bedrock Managed Knowledge Bases, Amazon Quick and AgentCore. 2.1, 3.1
  • Amazon Forecast: 29 July 2024; use SageMaker Canvas forecasting. 2.1
  • Amazon Fraud Detector: 7 November 2025. 2.1
  • Comprehend topic modeling, event detection and prompt safety classification: 30 April 2026; toxicity and PII detection are unaffected. 1.3
  • Rekognition streaming video and bulk image analysis: 30 April 2026; People Pathing ended on 31 October 2025. 2.1
  • AWS Audit Manager: no longer accepts new customers. 4.3
  • Amazon CodeGuru: Reviewer takes no new repository associations, and CodeGuru Security is no longer documented; use Amazon Inspector and Amazon Q code reviews. 4.3

Ended or retired

  • SageMaker Edge Manager: end of life 26 April 2024; use ONNX or Neo with IoT Greengrass V2. 3.1
  • Elastic Inference: no longer available. 3.1
  • Original SageMaker Operators for Kubernetes: ended February 2023; the ACK SageMaker controller replaces them. 3.1
  • CloudWatch Evidently (the feature-flag service, not the open-source Evidently library): discontinued October 2025. 4.1
  • Bedrock models: many older models are Legacy or end of life (all Meta Llama models, Claude 3 Haiku fine-tuning). 2.1

Maintenance or changed

  • AWS X-Ray SDKs and daemon: maintenance mode from 25 February 2026; use OpenTelemetry. 4.2
  • AWS CodeCommit: closed to new customers on 25 July 2024, open again since 25 November 2025; the SageMaker Projects CodeCommit templates haven't returned. 3.3
  • SageMaker Python SDK v3 (November 2025): ModelTrainer and ModelBuilder replace Estimator, Model and Predictor. 2.2
  • Autopilot: its interface moved into Canvas (November 2023); the API remains. 2.1
  • Bedrock data retention: retention modes now decide whether prompts are stored for some models. 4.3

Renamed services

Old names still appear in questions, blog posts and older guides. Same service, new name:

  • Amazon SageMaker is now Amazon SageMaker AI (3 December 2024).
  • Amazon Bedrock Agents is now Amazon Bedrock Agents Classic.
  • AWS CodeStar Connections is now AWS CodeConnections (March 2024).
  • SageMaker Data Wrangler now lives inside SageMaker Canvas.
  • Prompt Flows is now Amazon Bedrock Flows.
  • Glue FindMatches is documented as Lake Formation record matching.
  • Amazon Kinesis Data Firehose is now Amazon Data Firehose, and Kinesis Data Analytics is Amazon Managed Service for Apache Flink.

Out of scope

The guide's out-of-scope list is long and non-exhaustive. The entries closest to this exam's topics:

  • Analytics: AWS Clean Rooms, Amazon DataZone, Amazon FinSpace.
  • Application integration: Amazon AppFlow, Amazon MQ, Amazon SWF.
  • Compute and containers: AWS App Runner, Elastic Beanstalk, Lightsail, Outposts, Red Hat OpenShift Service on AWS.
  • Developer tools: Infrastructure Composer, CloudShell, CodeCatalyst, Fault Injection Service.
  • Internet of Things: AWS IoT Core, IoT Greengrass and the other IoT services.
  • Machine learning: AWS DeepRacer, HealthImaging, HealthOmics.
  • Management and governance: Control Tower, AppConfig, License Manager, Amazon Managed Grafana, Proton, Resilience Hub, Resource Explorer, User Notifications.
  • Networking: Route 53 and its Application Recovery Controller, Global Accelerator, Cloud Map, App Mesh, VPC IPAM.
  • Security: Audit Manager, ACM, CloudHSM, Cognito, Detective, Firewall Manager, GuardDuty, Payment Cryptography, Private CA, RAM, Security Hub and Security Hub CSPM, Shield, Signer, Verified Permissions, WAF.
  • Also business applications, end-user computing, frontend and mobile, media, migration services and Elastic Disaster Recovery.

Out of the list isn't out of the exam. A few out-of-scope services appear in these notes because a current AWS answer uses them (GuardDuty AI Protection for model abuse, Cognito for work teams, Greengrass at the edge). Know what they do in one sentence; questions focus on the in-scope services.
