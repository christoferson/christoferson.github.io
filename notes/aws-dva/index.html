How to use this guide

The exam is for developers with a year or more of hands-on experience building and maintaining applications on AWS. It tests writing code against AWS services, securing it, packaging and deploying it with CI/CD, and finding and fixing problems, now including AI-assisted development tools and calling managed AI services. Designing architectures, creating pipelines and choosing or prompting foundation models are out of scope.

  1. Start with Domain 1Nearly a third of the exam: application code that uses AWS services, Lambda, and data stores. The other domains build on it.
  2. Then Domain 2Authentication, authorization, encryption and secrets, and the security risks of building with AI services.
  3. Then Domains 3 and 4Packaging, testing and deploying through CI/CD, then root cause analysis, observability and optimization.

DVA-C03 replaces DVA-C02: registration for DVA-C03 opens December 1, 2026, and the last day to take DVA-C02 is November 30, 2026. The new version adds AI-assisted development (Kiro), managed AI services (Amazon Bedrock and AgentCore) and AI service security. Some services the guide names have changed status, for example the AWS Copilot CLI (end of support June 12, 2026) and the AWS X-Ray SDKs (maintenance mode; OpenTelemetry is the successor). These notes keep the exam's wording for each skill but teach the current service, with a callout where it matters.
