Overview

The exam guide's appendix lists the services and features that questions may involve, in eleven categories. The list isn't exhaustive, and a listed service doesn't mean many questions: Lambda, API Gateway, DynamoDB, SQS, SNS, IAM, CloudFormation and SAM, the Code services and CloudWatch appear far more than EFS or Route 53. A few services appear only in the skill statements (Fargate, DAX, Copilot); they're listed after the categories.

For each service, the "Covered in" column links to the task sections where it's explained. "Background" means the notes mention it only in passing or not at all: know what it does. The cheat sheet maps question clues to services.

"Amazon Quick" is in scope (as an AI service) while "Amazon Quick Sight" is out of scope. Some services these notes use are on neither list, such as Amazon Comprehend, Textract, Transcribe and Translate (managed AI services in Task 1.1), Amazon Macie, Amazon Inspector, AWS Compute Optimizer and AWS DevOps Agent. Treat them as background: know what each is for.
