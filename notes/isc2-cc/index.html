How to use this guide

The exam is for people starting out in cybersecurity: there are no prerequisites beyond basic IT knowledge, and no work experience is required. These notes follow the exam outline in effect since September 1, 2026, which renamed and reweighted the domains and weaves AI security into each of them. They explain each objective in their own words, using public standards from NIST and CISA; the official outline itself is on isc2.org.

  1. Start with Domain 1The principles every other domain builds on: what security protects, how risk is managed, governance, the kinds of controls, and professional ethics.
  2. Then Domains 2 and 3How organizations govern security and stay resilient, and how identities and access are controlled.
  3. Then Domains 4 and 5Protecting networks and cloud services, then the day-to-day of security operations, incident response and testing.

About the exam in 2026. CC uses computerized adaptive testing: 100 to 125 questions in up to two hours, with no going back to review an answer. It is taken at Pearson VUE test centers only. The exam fee is US$199. ISC2's free "One Million Certified in Cybersecurity" program closed to new enrollments on May 20, 2026, so older advice that CC is free no longer applies.
