Study notes for the Kubernetes and Cloud Native Security Associate

Security for Kubernetes® and cloud native systems: how each cluster component is protected, how Pods, identities, Secrets and networks are locked down, how attackers move through a cluster, and the platform tools and frameworks used to defend it, as described by Kubernetes and CNCF® sources.

How to use this guide

KCSA is an entry-level security exam with no prerequisites. Its curriculum lists six weighted domains and 43 short topic names; these notes group related topics onto 20 pages, explain each from the Kubernetes documentation and CNCF sources, and show real kubectl commands and YAML manifests against Kubernetes v1.37. Each page names the curriculum topics it covers.

  1. Start with Domains 1 and 2The big picture of cloud native security, then what each control plane and node component exposes and how it is hardened.
  2. Then Domain 3The built-in controls: Pod Security, authentication and authorization, Secrets, network policy and audit logging.
  3. Then Domains 4 to 6How attacks unfold in a cluster, the platform tools that defend it, and the frameworks used to model threats and prove compliance.

About the exam in 2026. KCSA is an online, proctored, multiple-choice exam taken through PSI: 60 questions in 90 minutes, with 75% needed to pass. It costs US$250 including one free retake, the certification is valid for two years, and it is one of the five exams needed for Kubestronaut. The curriculum has not changed since June 2024, but the security landscape has: the kubernetes.io page on the "4Cs" was removed in 2024, PodSecurityPolicy is long gone, and several tools have changed CNCF status.
