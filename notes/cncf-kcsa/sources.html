How to use this register

Version or date

The KCSA curriculum PDF has no version number; its only content change since launch was the June 2024 fix of Domain 6 from 16% to 10%. Kubernetes documentation follows the minor release (v1.37 when checked), MITRE ATT&CK was at v20.1, and most other pages are living pages, so the date they were read is what matters.

Licence and quoting

Each group says how its text may be used. CC BY 4.0, Apache-2.0 and public US government sources are quoted with attribution in the page footers. CIS benchmarks are described only, never reproduced; PCI, ISO and AICPA material is paraphrased; MITRE names carry the MITRE notice; CC BY-SA OWASP text is quoted only briefly.

KCSA curriculum and exam pages

Licence and quotingThe curriculum is CC BY 4.0 (cncf/curriculum README): domain and topic names are shown verbatim with attribution. Linux Foundation exam pages and the certification agreement are not openly licensed: facts only, short quotes.

Version or dateKCSA Curriculum PDF (no version number; first committed February 22, 2024; Domain 6 corrected from 16% to 10% in June 2024, the only content change). The Linux Foundation exam page (modified July 28, 2026) shows the same six domains.

Facts recordedSix domains: Overview of Cloud Native Security 14%, Kubernetes Cluster Component Security 22%, Kubernetes Security Fundamentals 22%, Kubernetes Threat Model 16%, Platform Security 16%, Compliance and Security Frameworks 10%, grouped here into 20 topic pages. Exam: online proctored via PSI, 60 multiple-choice questions, 90 minutes, 75% to pass, US$250 with one free retake, 12 months to schedule, valid 2 years (passing CKS renews it), English only, no prerequisites.

Discrepancykcsa/README.md (added November 28, 2025 in commit "Add Recognition of the exam authors (#97)", unchanged when re-checked November 8, 2026) lists six different domains: Cloud Native Fundamentals 16%, Kubernetes Security Fundamentals 20%, Container Security Fundamentals 20%, Secure Software Supply Chain 16%, Monitoring, Logging and Runtime Security 12%, General Security Knowledge 16%. The PDF and the Linux Foundation exam page agree with each other, so the guide follows them. Either the README is wrong or it previews a revision: watch for a new curriculum PDF or a program-changes notice, as happened for KCNA in 2025.

Refreshing the guide

When to refresh

  • The KCSA curriculum or the Linux Foundation exam page changes (domains, weights, price, validity). Watch in particular for a new curriculum PDF that matches the six domains in kcsa/README.md (see the curriculum entry above).
  • A new Kubernetes minor release, about three times a year (v1.38 is due December 16, 2026): feature states, admission plugins, PKI features and version-specific numbers on every topic page.
  • A new MITRE ATT&CK release (usually April and October), a new CIS Kubernetes Benchmark, or a status change of a CNCF security project.
  • Six months have passed since the last check (next: May 2027).

What to re-check first

Kubernetes features: ClusterTrustBundle and Pod Certificates (GA in v1.37), manifest-based admission control (beta), MutatingAdmissionPolicy (GA in v1.36), the default admission plugin list, Pod Security Standards, Secrets encryption and KMS v2, audit policy, structured authentication and authorization configuration.

Policy and supply chain projects: Kyverno 1.20 (planned removal of ClusterPolicy, deprecated verifyImages, the CLI's ValidatingPolicy support), Gatekeeper and gator, cosign and Sigstore, SLSA versions and tracks, in-toto and TUF status, Harbor, cert-manager supported versions, Gateway API TLS features.

Matrices, benchmarks and tools: ATT&CK Containers tactics (Stealth and Defense Impairment since v19), the Microsoft Threat Matrix for Kubernetes, CIS benchmark 2.1.0 and kube-bench, Trivy and Kubescape compliance specs, Falco rule maturity, Istio and Linkerd releases, deprecated tools (Datree, kubeaudit, kube-hunter), Falco Talon status.

Rules and frameworks: EU Cyber Resilience Act dates (main obligations December 11, 2027), NIS2 and DORA, the HIPAA Security Rule proposal, PCI DSS revisions, NIST SSDF v1.2 (draft), CISA SBOM minimum elements, FedRAMP 20x, SOC 2 2027 criteria, and the rewritten OWASP Threat Modeling Cheat Sheet.
