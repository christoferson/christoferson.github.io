ServiceWhat it isChoose it when
Kinesis Data StreamsOrdered, replayable records partitioned into shards; retention 24 hours to 365 daysAWS-native ingestion with several consumers and replay

Often confused pairs

PairThe difference
Kinesis Data Streams and FirehoseA replayable stream you read versus a delivery service that writes to a store
push_down_predicate and catalogPartitionPredicatePrunes after listing partitions versus prunes on the catalog server with partition indexes
MSCK REPAIR TABLE and partition projectionRegisters Hive-style partitions versus Athena computes them, registering nothing
Expiration and NoncurrentVersionExpirationAdds a delete marker to the current version versus permanently deletes old versions
IsComplete and ColumnValues != EMPTYFails on nulls only versus also catches empty strings
COPY and COPY JOBA one-time load versus automatic loading of new files only
EXPLAIN and EXPLAIN ANALYZEShows the plan for free versus runs and bills the query
LF-Tags and IAM tagsLake Formation labels on catalog objects versus tags on principals and AWS resources
Data filters and dynamic data maskingRemoves rows or columns versus shows altered values
Pseudonymization and anonymizationStill linkable to a person (still personal data) versus not linkable
Log file validation and Object LockDetects tampering versus prevents deletion
Data residency and data sovereigntyWhere data is stored versus who controls it and which laws apply
SCP and RCPLimits what your principals can do versus who can reach your resources
Redshift datashare consumer with and without WITH PERMISSIONSUSAGE grants nothing until per-object grants versus USAGE opens everything
