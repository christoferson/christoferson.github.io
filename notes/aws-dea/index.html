How to use this guide

The exam is for data engineers with two to three years of data engineering experience and one to two years of hands-on AWS work. It tests designing and running pipelines, choosing data stores and formats, operating and monitoring data workloads, and securing and governing data; training ML models and language-specific syntax are out of scope. These notes follow exam guide version 1.1 (December 2025), which added open table formats, vector indexes, SageMaker Unified Studio and Catalog, and LLM-based processing.

  1. Start with Domain 1A third of the exam: ingestion, transformation, orchestration and the programming concepts behind them.
  2. Then Domain 2Choosing stores, catalogs, lifecycle and data modeling, which every pipeline depends on.
  3. Then Domains 3 and 4Automating, analyzing, monitoring and assuring quality, then authentication, authorization, encryption, audit logs and governance.

The exam guide names some services that have since changed: Amazon QuickSight is now Amazon Quick (its BI part is Amazon Quick Sight), Kinesis Data Firehose is Amazon Data Firehose, Amazon Kendra and AWS CloudTrail Lake are closed to new customers, and AWS Glue versions 2.0 and earlier have reached end of life. These notes keep the exam's wording for each skill but teach the current service, with a callout where it matters.
