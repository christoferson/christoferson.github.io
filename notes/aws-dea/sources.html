Exam guide

AWS Certified Data Engineer – Associate (DEA-C01) exam guide

Version or dateVersion 1.1, published December 12, 2025 (version 1.0 was the first release). AWS says guide updates are published about one month before they reach the exam. No DEA-C02 or DEA-C01 retirement had been announced when checked.

Facts recorded65 questions (50 scored, 15 unscored), 130 minutes, 150 USD, pass 720 of 1,000. Four domains: Data Ingestion and Transformation 34%, Data Store Management 26%, Data Operations and Support 22%, Data Security and Governance 18%, with 17 tasks and 120 skills. Version 1.1 merged knowledge and skills into one skill list per task and added eight skills: 1.2.10 (LLMs for data processing), 2.1.7 (open table formats), 2.1.8 (vector index types), 2.2.6 (business data catalogs), 2.4.6 (vectorization), 4.1.7 (SageMaker Unified Studio domains, domain units and projects), 4.5.6 (SageMaker Catalog project access) and 4.5.7 (governance frameworks and sharing patterns). Guide inconsistencies handled on the pages: skill 2.4.3 still names AWS SCT, which is no longer in scope; skills 3.2.1 and 3.2.2 still say QuickSight (now Amazon Quick Sight); skill 4.4.3 names CloudTrail Lake, which closed to new customers on May 31, 2026.
