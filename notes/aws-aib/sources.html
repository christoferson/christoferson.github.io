How to use this register

Version or date

The publication date or version shown on the source when it was used. AWS whitepapers and Well-Architected lenses show a publication date and a "Document revisions" page; AWS service guides are living documents without a version, so for those the check date is what matters.

Last checked

When the source was last read to confirm the guide still matches it.

Used on

The pages that rely on the source. When a source has a new revision, review these pages.

  1. Check each dated sourceOpen its document revisions page and compare the latest date with the one recorded here.
  2. Check living documents and status changesRe-read the specific topics listed, especially service availability and lifecycle notices.
  3. Update the pages listed under "Used on"Then update the version and "last checked" dates here.
