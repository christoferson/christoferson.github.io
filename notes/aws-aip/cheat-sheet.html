The exam

AIP-C01 at a glance
Format
180 minutes, 75 questions: 65 scored and 10 unscored (not identified). Delivered by Pearson VUE at a test center or online.
Scoring
Scaled 100 to 1,000; pass at 750.
Cost and languages
300 USD; English, Japanese, Korean and Simplified Chinese.
Domains
1 Foundation model integration, data management and compliance 31% · 2 Implementation and integration 26% · 3 AI safety, security and governance 20% · 4 Operational efficiency and optimization 12% · 5 Testing, validation and troubleshooting 11%
Helpful background
AWS suggests AI Practitioner, Solutions Architect Associate, Machine Learning Engineer Associate or Data Engineer Associate knowledge first.

Numbers worth knowing

Bedrock requests and limits
Converse attachments
Up to 20 images (3.75 MB, 8,000 px) and 5 documents (4.5 MB) per request
Request metadata
Up to 16 key-value pairs, recorded in invocation logs
Invocation logs
Bodies over 100 KB go to S3
Quota reservation
Input tokens plus maxTokens reserved at the start; billing on actual tokens
Batch inference
About 50% cheaper than on-demand; job timeout 24 to 168 hours; output order not guaranteed
Service tiers
Priority about +75%; Flex about −50%; Reserved minimum 100K input and 10K output tokens per minute, 1 or 3 months
Global cross-Region inference
About 10% cheaper than geographic
Prompt caching
Minimum 512 to 4,096 tokens by model; up to 4 checkpoints; 5-minute TTL (1 hour on newer Claude)
Knowledge bases and vectors
Results
numberOfResults 1 to 100, default 5
Chunking
Default about 300 tokens; fixed size up to 8,192 tokens; fixed at data source creation
Metadata file
At most 10 KB, same folder, FILE.metadata.json
Ingestion
50 MB per text file; 100 GB per job
Titan Text Embeddings V2
8,192 tokens; 1,024, 512 or 256 dimensions
Cohere Embed v3
512 tokens per text; truncates the end by default
OpenSearch HNSW defaults
m 16, ef_construction 100, ef_search 100; disk mode 32× compression
S3 Vectors
Up to 2 billion vectors per index, 4,096 dimensions; sub-second queries (about 100 ms when frequent)
Guardrails and evaluation
Denied topics
Up to 30; definition 200 characters (Classic) or 1,000 (Standard)
Grounding check input
Source 100,000 characters, query 1,000, response 5,000
Evaluation datasets
Up to 1,000 prompts; built-in datasets 100 prompts; up to 10 custom metrics
Human evaluation
Up to 2 models compared; up to 50 workers per team
Integration
API Gateway
Integration timeout 29 s by default (raisable for Regional and private REST APIs); payload 10 MB; REST response streaming up to 15 minutes
Lambda
Timeout up to 15 minutes; streamed responses up to 200 MB
Idle connections
NAT gateway, VPC endpoint and NLB drop idle TCP after 350 seconds
Step Functions
Bedrock InvokeModel body up to 256 KiB (use S3 for more); Standard runs up to 1 year, Express 5 minutes
AgentCore Runtime
Sessions up to 8 hours
