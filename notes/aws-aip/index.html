How to use this guide

The exam is for developers with about two years of building production applications and a year of hands-on generative AI work. It tests integrating, securing, operating and evaluating foundation models, not training them. The basics (what a foundation model, RAG or a prompt is) are covered in the AI Practitioner guide; this guide assumes them.

  1. Start with Domain 1A third of the exam: choosing models, data pipelines, vector stores, retrieval and prompts. Everything else builds on it.
  2. Then Domain 2Agents, deployment, enterprise integration and the APIs that connect models to applications.
  3. Then Domains 3, 4 and 5Safety and governance, cost and performance, then evaluation and troubleshooting, which revisit Domain 1 and 2 designs from an operations angle.

The exam guide still names some services by older names or that have changed status: Amazon Bedrock Prompt Flows (now Amazon Bedrock Flows), Amazon Bedrock Agents (now Agents Classic, closed to new customers; AgentCore is the successor), Amazon Q Developer (Kiro is the successor) and Amazon Kendra (closed to new customers). These notes keep the exam's wording for each skill but teach the current service, with a callout where it matters.
