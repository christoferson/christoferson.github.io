When to refresh

Triggers

  • A new guide version (this is version 1.0 of a new exam), or a Pearson VUE content-update notice for CCDV-P.
  • New models, price changes, or deprecation and retirement dates on the models and deprecations pages.
  • Changes to rate limits, batches, prompt caching, context management, mid-conversation system messages or the OpenTelemetry span names (beta).
  • Claude Code releases that change subagents, agent teams, worktrees, /goal, scheduled tasks (research preview), managed MCP or Code Review.
  • A new MCP specification revision, a new OWASP Top 10 for LLM Applications, or a revised NIST Generative AI Profile.
