How to use this page

Read each list from the top: posts are newest first, and a newer post on the same design usually replaces an older one. A note saying a post predates a feature means it describes an older approach; the design still works, but the current answer may use the newer feature. The posts come from the AWS Architecture, Compute, Database, Networking and Content Delivery, Storage, Security and News blogs, and the dates are publication dates.

Several services changed after many of these posts were written, such as App Runner closing to new customers, the Regional NAT gateway and new names for Route 53 VPC Resolver and Application Recovery Controller, so older posts use older names or patterns. The AWS services page lists the status changes.
