All architectures

Grouped by theme, using the same company and accounts as the task pages. Each page stands alone and links the SAP, ANS, SCS and DOP architectures where they go deeper.

Application architectures

  • Highly available web application: CloudFront, an Application Load Balancer and EC2 Auto Scaling across AZs, Aurora PostgreSQL Multi-AZ with replicas, ElastiCache and Route 53.
  • Serverless API: API Gateway, Lambda and DynamoDB with Cognito sign-in, throttling, caching and least-privilege roles.
  • Decoupled order processing: SQS queues with dead-letter queues, SNS fan-out, EventBridge rules and a Step Functions workflow, with idempotent consumers.

Network and security

  • Secure VPC and hybrid connectivity: Public and private subnets, NAT gateways, VPC endpoints, security groups, Transit Gateway and Site-to-Site VPN or Direct Connect to the office.

Storage and recovery

  • Uploads and content delivery: Presigned S3 uploads, event processing, CloudFront with origin access control, encryption and lifecycle rules to cheaper storage classes.
  • Disaster recovery on a budget: AWS Backup copies, backup and restore versus pilot light and warm standby in us-west-2, Aurora Global Database and Route 53 failover.
