Overview

The exam guide (version 1.1) lists 118 services and features in sixteen categories (Amazon Redshift appears under both Analytics and Database). The list isn't exhaustive, and being listed doesn't mean many questions: VPC, IAM, EC2, Auto Scaling, ELB, S3, RDS, Aurora, DynamoDB, Lambda, SQS, CloudFront, Route 53 and KMS come up far more than Device Farm or License Manager. The guide uses current names such as Amazon Quick and Amazon SageMaker AI.

Each entry says what the service is for on this exam and links to the task sections that explain it. Background means the notes don't cover it: know in one sentence what it does. The cheat sheet maps question clues to services, and the comparisons page sets similar options side by side.

Analytics

  • Amazon Athena: serverless SQL on data in S3, priced per TB scanned; CTAS to convert to Parquet. 3.5, 3.5
  • AWS Data Exchange: find and subscribe to third-party datasets, delivered into S3. Background.
  • AWS Data Pipeline: older batch data movement service, now in maintenance mode; use Glue, Step Functions or MWAA. 3.5
  • Amazon EMR: managed Spark, Hive, Presto, HBase and Flink; Spot on task nodes, EMR Serverless. 3.2, 3.5
  • AWS Glue: serverless Spark ETL and the Data Catalog with crawlers. 3.5, 3.5, 3.5
  • Amazon Kinesis: Data Streams for ordered, replayable streams; Data Firehose for no-code delivery to S3, Redshift and OpenSearch. 2.1, 3.2, 3.5, 3.5
  • AWS Lake Formation: database-style grants on data lake tables, down to columns and rows; LF-Tags. 3.5
  • Amazon MSK: managed Apache Kafka, provisioned or Serverless. 3.2, 3.5
  • Amazon OpenSearch Service: search and log analytics with OpenSearch Dashboards; UltraWarm and cold tiers. 2.1, 3.5, 4.3
  • Amazon Quick: business intelligence dashboards (Amazon Quick Sight, formerly QuickSight) with SPICE and embedding. 3.5
  • Amazon Redshift: columnar data warehouse, provisioned (RA3, RG) or Serverless; Spectrum queries S3. 3.3, 3.5, 4.3

Application integration

  • Amazon AppFlow: managed data flows from SaaS applications such as Salesforce into S3 or Redshift. 3.5
  • Amazon EventBridge: event bus that routes AWS, SaaS and custom events by content; Pipes and Scheduler. 2.1, 2.1
  • Amazon MQ: managed ActiveMQ or RabbitMQ for applications that use JMS, AMQP or MQTT. 2.1, 2.2
  • Amazon SNS: push publish/subscribe and fan-out to SQS, Lambda, HTTP, email and SMS; filter policies. 2.1
  • Amazon SQS: queues that decouple and buffer work; standard or FIFO, visibility timeout, dead-letter queues. 2.1, 2.1, 3.2
  • AWS Step Functions: workflows as state machines with retries and error handling; Standard and Express. 2.1

Cost management

  • AWS Budgets: alerts on actual or forecast cost and usage, with actions. 4.1, 4.4
  • AWS Cost and Usage Report: line-item billing data, now CUR 2.0 in AWS Data Exports. 4.1, 4.4
  • AWS Cost Explorer: charts and forecasts of cost and usage; Savings Plans and RI recommendations. 4.1, 4.2, 4.4
  • Savings Plans: an hourly spend commitment for 1 or 3 years; Compute, EC2 Instance, SageMaker AI and Database plans. 4.2, 4.3

Compute

  • AWS Batch: queued batch jobs on Fargate, EC2 or Spot; array jobs. 3.2, 4.2
  • Amazon EC2: virtual servers; instance families and sizes, purchasing options, placement groups, hibernation. 3.2, 4.2, 4.2, 4.2
  • Amazon EC2 Auto Scaling: groups of instances across AZs with target tracking, scheduled and predictive scaling, warm pools. 2.1, 3.2, 4.2
  • AWS Elastic Beanstalk: deploys web applications and manages their capacity, load balancing and scaling. 3.2
  • AWS Outposts: AWS racks and servers in your data center, linked to a Region. 3.2, 3.1, 4.2
  • AWS Serverless Application Repository: publish and deploy reusable serverless (SAM) applications. Background.
  • VMware Cloud on AWS: run VMware environments on dedicated AWS infrastructure. Background.
  • AWS Wavelength: compute inside telecom 5G networks for the lowest mobile latency. 3.2

Containers

  • Amazon ECR: managed container image registry with scanning and replication. 2.1
  • Amazon ECS: AWS's container orchestrator, on Fargate, EC2 or ECS Managed Instances. 2.1, 4.2
  • Amazon ECS Anywhere: ECS tasks on your own on-premises servers. Background.
  • Amazon EKS: managed Kubernetes; Auto Mode, Karpenter, extended support charges. 2.1, 3.2, 4.2
  • Amazon EKS Anywhere: run EKS-style Kubernetes clusters on your own infrastructure. Background.
  • Amazon EKS Distro: the Kubernetes distribution EKS uses, for your own clusters. Background.

Database

  • Amazon Aurora: MySQL- and PostgreSQL-compatible relational database with six-way storage, 15 replicas, Global Database, I/O-Optimized. 2.2, 3.3, 3.3, 4.3
  • Amazon Aurora Serverless: Aurora capacity that scales in ACUs and can pause at 0. 2.1, 3.3, 4.3
  • Amazon DocumentDB: MongoDB-compatible document database. 2.1, 4.3
  • Amazon DynamoDB: serverless key-value and document database; capacity modes, keys and indexes, global tables, DAX. 3.3, 2.2, 4.3
  • Amazon ElastiCache: in-memory cache (Valkey, Redis OSS, Memcached), node-based or serverless. 3.3, 2.1, 4.3
  • Amazon Keyspaces: Cassandra-compatible wide-column database. 2.1, 4.3
  • Amazon Neptune: graph database for relationships, fraud detection and recommendations. 2.1
  • Amazon RDS: managed relational databases on six engines; Multi-AZ, read replicas, RDS Proxy, Reserved Instances. 2.2, 3.3, 3.3, 4.3
  • Amazon Redshift: see Analytics above.

Developer tools

  • AWS X-Ray: request tracing and a service map; its SDKs and daemon are now in maintenance mode in favour of OpenTelemetry. 2.2

Front-end web and mobile

  • AWS Amplify: build and host full-stack web and mobile applications; can be protected by AWS WAF. Background (1.2 mentions WAF support).
  • Amazon API Gateway: REST, HTTP and WebSocket APIs; throttling, usage plans, caching, private APIs. 2.1, 4.4
  • AWS Device Farm: test web and mobile apps on real devices and browsers. Background.

Machine learning

The exam treats these as managed, purpose-built services you call instead of building models; all are covered in Task 2.2.

  • Amazon Comprehend: natural language processing: sentiment, entities, key phrases, PII detection.
  • Amazon Lex: conversational chatbots.
  • Amazon Polly: text to speech.
  • Amazon Rekognition: image and video analysis, faces, unsafe content.
  • Amazon SageMaker AI: build, train and deploy your own machine learning models.
  • Amazon Textract: text, forms and tables from documents.
  • Amazon Transcribe: speech to text.
  • Amazon Translate: language translation.

Management and governance

  • AWS Auto Scaling: scaling plans across several resource types; AWS now recommends predictive scaling policies on each resource instead. 3.2
  • AWS CLI: the command line interface used in the examples throughout. Background.
  • AWS CloudFormation: infrastructure as code; change sets, rollback triggers, drift detection, StackSets. 2.2
  • AWS CloudTrail: API activity logs; log file integrity validation for audits. 1.3
  • Amazon CloudWatch: metrics, alarms and composite alarms, logs, Synthetics, Application Signals, Database Insights. 2.2, 3.2
  • AWS Compute Optimizer: right-sizing and idle-resource recommendations for EC2, EBS, Lambda, Fargate, databases and NAT gateways. 3.2, 4.2
  • AWS Config: configuration history and compliance rules, conformance packs, remediation. 1.3, 2.2
  • AWS Control Tower: landing zones with preventive, detective and proactive controls and Account Factory. 1.1
  • AWS Health Dashboard: AWS service events and scheduled changes that affect your resources. Background.
  • AWS License Manager: track and enforce software licence usage, such as per-core licences on Dedicated Hosts. Background.
  • Amazon Managed Grafana: managed Grafana dashboards for operational metrics, logs and traces. 3.5
  • Amazon Managed Service for Prometheus: Prometheus-compatible metrics storage for containers. Background.
  • AWS Management Console: the web console. Background.
  • AWS Organizations: multiple accounts under one organization: OUs, SCPs, RCPs, consolidated billing. 1.1, 4.1
  • AWS Proton: infrastructure templates for platform teams; reached end of support on 7 October 2026. 2.2
  • AWS Service Catalog: approved products that users can launch; Control Tower's Account Factory uses it. Background.
  • AWS Systems Manager: fleet operations: Session Manager, Patch Manager, State Manager, Automation, Parameter Store. 1.2, 1.2, 2.2, 4.2
  • AWS Well-Architected Tool: review workloads against the Well-Architected Framework's pillars. Background.

Media services

  • Amazon Kinesis Video Streams: ingest and store video from cameras for playback and analysis. 3.5

Migration and transfer

  • AWS Application Discovery Service: inventory of on-premises servers for migration planning; closed to new customers. Background.
  • AWS Application Migration Service: rehost servers by continuous block replication; AWS now presents it as AWS Transform MGN. 4.1
  • AWS DataSync: online transfer between NFS, SMB, HDFS, other clouds and S3, EFS or FSx. 3.1, 4.1, 4.1
  • AWS DMS: database migration with full load and change data capture; Schema Conversion and DMS Serverless. 3.3, 4.3
  • AWS Snow Family: offline transfer devices, no longer available to new customers. 3.1, 4.1
  • AWS Transfer Family: managed SFTP, FTPS, FTP and AS2 into S3 or EFS. 2.1, 3.5, 4.1

Networking and content delivery

  • AWS Client VPN: managed VPN for individual users' devices. 1.2
  • Amazon CloudFront: content delivery network; OAC, VPC origins, functions, price classes, origin failover. 2.1, 3.4, 4.4
  • AWS Direct Connect: private dedicated or hosted connections; VIFs, Direct Connect gateway, LAGs, MACsec. 1.2, 3.4, 4.4, 4.4
  • Elastic Load Balancing: Application, Network and Gateway Load Balancers; routing, algorithms, cross-zone, cost. 2.1, 3.4, 4.2
  • AWS Global Accelerator: static anycast IPs with fast Regional failover for TCP and UDP. 2.1, 3.4, 4.4
  • AWS PrivateLink: interface endpoints to AWS services and to your own services in other VPCs. 1.2, 3.4
  • Amazon Route 53: DNS with routing policies and health checks; Resolver endpoints for hybrid DNS. 2.2, 3.4, 4.4
  • AWS Site-to-Site VPN: IPsec tunnels from on-premises networks; large-bandwidth tunnels and ECMP on a transit gateway. 1.2, 4.4
  • AWS Transit Gateway: Regional hub for VPCs, VPNs and Direct Connect; route tables, peering, 1:1 NAT. 3.4, 3.4, 4.4
  • Amazon VPC: subnets, route tables, security groups, NACLs, NAT gateways, endpoints, IPAM. 1.2, 1.2, 3.4, 4.4

Security, identity and compliance

  • AWS Artifact: AWS's compliance reports and agreements such as the HIPAA BAA. 1.3
  • AWS Certificate Manager: TLS certificates with managed renewal; us-east-1 for CloudFront. 1.2, 1.3
  • AWS CloudHSM: single-tenant HSMs under your control. 1.3
  • Amazon Cognito: user pools for customer sign-in, identity pools for AWS credentials. 1.1
  • Amazon Detective: root-cause investigation of security findings. 1.2
  • AWS Directory Service: AWS Managed Microsoft AD, AD Connector and Simple AD. 1.1
  • AWS Firewall Manager: central WAF, Shield, security group and firewall policies across an organization. 1.2
  • Amazon GuardDuty: threat detection from CloudTrail, VPC Flow Logs and DNS logs. 1.2
  • AWS IAM Identity Center: workforce single sign-on to many accounts with permission sets. 1.1
  • Amazon Inspector: vulnerability scanning of EC2, container images, Lambda and code. 1.2
  • AWS KMS: encryption keys, key policies and grants, rotation, multi-Region keys. 1.3, 1.3, 1.3
  • Amazon Macie: discovers sensitive data in S3. 1.2, 3.5
  • AWS Network Firewall: managed stateful firewall and intrusion prevention for VPCs. 1.2
  • AWS RAM: share subnets, transit gateways, security groups and other resources across accounts. 1.2, 3.4
  • AWS Secrets Manager: stores and rotates credentials. 1.2
  • AWS Security Hub: posture checks (now Security Hub CSPM) and the new Security Hub that prioritizes findings. 1.2, 1.3
  • AWS Shield: DDoS protection, Standard (free) and Advanced. 1.2
  • AWS WAF: web application firewall: managed rules, rate-based rules, Bot Control. 1.2, 4.4
  • IAM: users, groups, roles and policies; policy evaluation, permissions boundaries, STS. 1.1, 1.1, 1.1, 1.1

Serverless

  • AWS Fargate: serverless containers for ECS and EKS, billed per task; Fargate Spot. 2.1, 3.2, 4.2
  • AWS Lambda: event-driven functions up to 15 minutes; memory sizing, concurrency, pricing. 2.1, 3.2, 4.2

Storage

  • AWS Backup: central backup plans, Vault Lock, logically air-gapped vaults, cross-Region and cross-account copies. 1.3, 4.1
  • Amazon EBS: block volumes in one AZ: gp3, io2 Block Express, st1, sc1; snapshots. 3.1, 3.1, 4.1
  • Amazon EFS: serverless shared NFS file system for Linux; throughput modes and storage classes. 2.1, 3.1, 4.1
  • Amazon FSx: FSx for Windows File Server, Lustre, NetApp ONTAP and OpenZFS. 2.1, 3.1, 2.2
  • Amazon S3: object storage: storage classes, lifecycle, replication, Object Lock, performance. 1.3, 3.1, 4.1, 4.1
  • Amazon S3 Glacier: the Glacier storage classes (Instant Retrieval, Flexible Retrieval, Deep Archive). 4.1, 4.1
  • AWS Storage Gateway: S3 File, Volume and Tape Gateways for on-premises access to AWS storage. 3.1

Renamed services

Old names still appear in questions, blog posts and the guide itself. Same service, new name:

  • Amazon QuickSight is now Amazon Quick; the BI part is Amazon Quick Sight.
  • Amazon Kinesis Data Firehose is now Amazon Data Firehose.
  • Kinesis Data Analytics for Apache Flink is now Amazon Managed Service for Apache Flink.
  • Amazon SageMaker is now Amazon SageMaker AI.
  • Route 53 Application Recovery Controller is now Amazon Application Recovery Controller (ARC).
  • Route 53 Resolver is now Route 53 VPC Resolver.
  • AWS Security Hub (the posture checks) is now AWS Security Hub CSPM; the name Security Hub now belongs to the newer findings service.
  • AWS Single Sign-On (AWS SSO) is now AWS IAM Identity Center.
  • AWS Chatbot is now Amazon Q Developer in chat applications.
  • AWS Application Migration Service is now presented as AWS Transform MGN.
  • AWS Cost and Usage Report lives on as CUR 2.0 in AWS Data Exports.

Out of scope

The guide lists these as out of scope, verbatim. The list isn't exhaustive. Version 1.1 removed Amazon Elastic Transcoder from the in-scope list and dropped DeepComposer, DevOps Guru, Elastic Inference, Managed Blockchain and Sumerian from this list.

  • Application Integration: Amazon Managed Workflows for Apache Airflow (Amazon MWAA)
  • Compute: Amazon Lightsail
  • Database: Amazon RDS on VMware
  • Developer Tools: AWS CDK, AWS CloudShell, AWS CodeArtifact, AWS CodeBuild, AWS CodeCommit, AWS CodeDeploy, Amazon Corretto, AWS Fault Injection Simulator (AWS FIS), AWS Tools and SDKs
  • Front-End Web and Mobile: Amazon Location Service
  • Game Tech: Amazon GameLift
  • Internet of Things: All services
  • Machine Learning: Apache MXNet on AWS, AWS Deep Learning AMIs (DLAMI), AWS Deep Learning Containers, Amazon HealthLake, AWS Inferentia, Amazon Personalize, PyTorch on AWS, TensorFlow on AWS
  • Management and Governance: AWS Console Mobile Application, AWS Distro for OpenTelemetry
  • Media Services: AWS Elemental Appliances and Software, AWS Elemental MediaConnect, AWS Elemental MediaConvert, AWS Elemental MediaLive, AWS Elemental MediaPackage, AWS Elemental MediaTailor, Amazon Interactive Video Service (Amazon IVS)
  • Migration and Transfer: Migration Evaluator
  • Networking and Content Delivery: AWS Cloud Map
  • Quantum Technologies: Amazon Braket
  • Satellite: AWS Ground Station

Out of scope isn't never seen. Several of these (MWAA, Lightsail, CodeDeploy, FIS, Personalize) appear in the task pages as wrong answers or as context for an in-scope service. Know them well enough to rule them out.
