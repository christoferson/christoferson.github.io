Often confused pairs

  • Security group and NACL: Stateful allow-only filter on an interface versus stateless allow-and-deny filter on a subnet.
  • Read replica and Multi-AZ standby: Scales reads with asynchronous copies versus survives failure with a synchronous standby.
  • Regional RI and zonal RI: Discount with size and AZ flexibility versus discount plus a capacity reservation in one AZ.
  • Savings Plan and Capacity Reservation: A discount with no capacity guarantee versus a capacity guarantee with no discount.
  • Gateway endpoint and NAT gateway: Free private route to S3 or DynamoDB versus a paid path to the whole internet.
  • Kinesis Data Streams and Data Firehose: Replayable stream for custom consumers versus buffered delivery into storage.
  • CloudFront Functions and Lambda@Edge: Sub-millisecond viewer logic at US$0.10 per million versus full functions with network access at US$0.60 per million.
  • S3 Transfer Acceleration and CloudFront: Faster long-distance uploads into one bucket versus cached delivery to viewers.
  • Object Lock governance and compliance: Overridable with permission versus not overridable by anyone.
  • Stop and hibernate: Instance restarts from boot versus resumes with its memory restored.
  • API Gateway usage plan and AWS Budgets: Best-effort per-client throttling versus actual cost alerts and actions.
  • Secrets Manager and Parameter Store: Stores and rotates secrets versus stores configuration and secrets without rotation.
