AWS Certified Advanced Networking – Specialty

Designing, implementing, operating and securing AWS and hybrid networks at scale: edge services, DNS and load balancing, routing and connectivity between on-premises networks, accounts, Regions and VPCs, network automation, monitoring and troubleshooting, and network security and confidentiality.

This exam is retiring. AWS's certification page says the last day to take ANS-C01 is December 31, 2026, and no replacement exam has been announced. Certifications earned before then stay active for the normal three years. These notes are being rebuilt task by task in the current guide format.

How to use these notes

The exam is for experienced network engineers: AWS recommends five or more years of networking experience, including two or more years of cloud and hybrid networking. Each task page explains every knowledge and skill statement in the official exam guide with one running example, a global online travel company with two data centers, several AWS Regions and many accounts. Pages not yet rebuilt are older-format notes; the topic notes go deeper into individual services.

  1. Start with Domain 1The largest domain (30%): edge services, DNS, load balancing, monitoring requirements, and hybrid and multi-account routing designs.
  2. Then Domains 2 and 4Implementing hybrid, multi-account and DNS connectivity and automation (26%), then network security, auditing and confidentiality (24%).
  3. Finish with Domain 3Maintaining routing, analyzing traffic and optimizing performance, reliability and cost (20%).

About the exam. ANS-C01 has 65 questions (50 scored, 15 unscored) in 170 minutes, with a passing score of 750 on a scale of 100 to 1,000. It costs US$300 and is offered at Pearson VUE test centres or online, in English, Japanese, Korean and Simplified Chinese.

Status changes since the exam guide. AWS App Mesh is still in the exam guide's scope but reached end of support on September 30, 2026; Amazon ECS Service Connect is the migration path. Newer networking features include VPC Block Public Access, VPC Route Server, PrivateLink cross-Region access, Site-to-Site VPN large bandwidth tunnels, Transit Gateway native AWS Network Firewall attachments, CloudFront VPC origins, and Route 53 Profiles.

Content domains

Domain names, weights and task statements are from the official exam guide.

Domain 1Network Design

30%of scored content
  • 1.1Design a solution that incorporates edge network services to optimize user performance and traffic management for global architectures
  • 1.2Design DNS solutions that meet public, private, and hybrid requirements
  • 1.3Design solutions that integrate load balancing to meet high availability, scalability, and security requirements
  • 1.4Define logging and monitoring requirements across AWS and hybrid networks
  • 1.5Design a routing strategy and connectivity architecture between on-premises networks and the AWS Cloud
  • 1.6Design a routing strategy and connectivity architecture that include multiple AWS accounts, AWS Regions, and VPCs to support different connectivity patterns

Domain 2Network Implementation

26%of scored content
  • 2.1Implement routing and connectivity between on-premises networks and the AWS Cloud
  • 2.2Implement routing and connectivity across multiple AWS accounts, Regions, and VPCs to support different connectivity patterns
  • 2.3Implement complex hybrid and multi-account DNS architectures
  • 2.4Automate and configure network infrastructure

Domain 3Network Management and Operation

20%of scored content
  • 3.1Maintain routing and connectivity on AWS and hybrid networks
  • 3.2Monitor and analyze network traffic to troubleshoot and optimize connectivity patterns
  • 3.3Optimize AWS networks for performance, reliability, and cost-effectiveness

Domain 4Network Security, Compliance, and Governance

24%of scored content
  • 4.1Implement and maintain network features to meet security and compliance needs and requirements
  • 4.2Validate and audit security by using network monitoring and logging services
  • 4.3Implement and maintain confidentiality of data and communications of the network
