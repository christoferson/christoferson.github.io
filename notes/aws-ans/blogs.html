How to use this page

Read each list from the top: posts are newest first, and a newer post on the same design usually replaces an older one. A note saying a post predates a feature means it describes an older approach; the design still works, but the current answer may use the newer feature. The posts come from the AWS Networking and Content Delivery blog and the AWS Architecture blog, and the dates are publication dates.

The exam guide itself predates many 2025 and 2026 features, so a question may still expect the older pattern. The status changes on the cheat sheet list what has changed since the guide was written.
