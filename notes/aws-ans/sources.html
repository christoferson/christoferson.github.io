Exam guide

AWS Certified Advanced Networking – Specialty (ANS-C01) exam guide

Version or dateANS-C01 is the current and only version. The certification page states the exam is being retired: the last day to take it is December 31, 2026, with no replacement announced. Certifications already earned stay active for the standard three years.

Facts recorded65 questions (50 scored, 15 unscored); multiple choice, multiple response and matching (the documentation guide lists multiple response and matching, the certification page multiple choice and multiple response); 170 minutes; 300 USD; pass 750 of 1,000 (compensatory scoring). Four domains: Network Design 30%, Network Implementation 26%, Network Management and Operation 20%, Network Security, Compliance, and Governance 24%; 16 tasks. Languages: English, Japanese, Korean and Simplified Chinese.

Refreshing the guide

When to refresh

  • AWS changes the retirement date or announces a successor networking exam.
  • A dated change recorded on the pages arrives: Developer, Business and Enterprise On-Ramp Support plans ending (January 1, 2027, which changes Trusted Advisor entitlements), ACM email validation ending (March and September 2027) and shorter ACM certificate validity (March 2027).

What to re-check first

Closures, renames and new features, which age fastest: App Mesh (end of support September 30, 2026), CloudTrail Lake (closed to new customers since May 31, 2026), ARC readiness check, Security Hub CSPM and the new Security Hub, WAF Classic end of life, Network Firewall proxy (preview), PrivateLink tunnel endpoints, Route 53 Global Resolver, Transit Gateway 1:1 NAT and policy-based routing, Direct Connect prefix controls, rate limiters and flat-rate pricing, and AWS Interconnect.

Versions: ELB and CloudFront TLS security policies, Cloud WAN policy versions, flow log field versions, and CDK ec2-alpha status.

Quotas and prices: Direct Connect and VPN quotas and prices, Transit Gateway and Cloud WAN pricing, PrivateLink and Lattice pricing, Network Firewall, WAF and Shield Advanced pricing, Resolver endpoint pricing, and ACM and Private CA pricing.
