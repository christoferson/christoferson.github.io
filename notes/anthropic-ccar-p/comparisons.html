ArchitectureFitsFails when

Error signals

Domain 3. Covered in skill 3.8.

SignalMeansResponse
429 with retry-afterRate or ramp limitWait as told; spread load; Batches for bulk
429 without retry-afterSpend cap reachedRetries won’t help; raise the cap or wait for the month
529Temporary overloadBackoff with jitter, then a fallback model
Other 4xxBad requestFix the request; don’t retry
200 with refusalThe model declinedNot an error to retry

Judge biases

Domain 4. Covered in skill 4.3.

BiasSignatureCorrection
PositionVerdict changes when order swapsJudge both orders; count consistent wins
VerbosityLonger answers win against human preferenceLength-neutral criteria, short anchors
Self-preferenceAgreement drops when its own model lostA judge from a different model
DriftAgreement on a fixed set falls over timePin the judge; re-check on a schedule

Permission modes

Domain 7. Covered in skill 7.2.

ModeRuns without askingFits
defaultReads; actions needing no approvalSensitive or unfamiliar code
acceptEditsPlus edits and common file commandsReviewing code as it’s written
planReads and exploration; no source editsExploring first (blocks edits when headless)
autoEverything, after a classifier checkLong tasks with a person nearby; not a guarantee
dontAskPre-approved tools; the rest deniedLocked-down CI and scripts
bypassPermissionsEverythingIsolated containers and VMs only
