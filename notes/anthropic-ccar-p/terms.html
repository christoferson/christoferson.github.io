Prompting and context

ReferencePrompt and context-engineering terms from Domain 2 and 3.

TermMeaningCovered in

Cache read shareShare of input tokens read from cache; Anthropic’s agent-loop median is 84%2.5
Context editingClearing old tool results from the conversation by rule (trigger, keep, exclude)2.6
CompactionSummarising older turns when the context reaches a threshold; lossy2.6
Memory toolClient-side file store Claude reads and writes, so state outlasts the window and restarts2.6
Context rotAccuracy falling as a context fills with irrelevant material3.7
Progressive discoveryLoading a map up front and fetching pieces with tools as needed3.7
Tool searchDeferred loading of tool definitions (defer_loading) so only relevant tools enter context3.1
Programmatic tool callingClaude writes code that calls tools, so intermediate results stay out of context3.1
Contextual retrievalPrepending 50 to 100 tokens of document context to each chunk before indexing3.5

Evaluation and optimisation

ReferenceMeasurement terms from Domain 4.

TermMeaningCovered in
Coverage gapA quality dimension (accuracy, groundedness, latency, cost, safety, security) the suite doesn’t measure4.1
Trajectory gradingGrading the steps and tool arguments, not only the final text4.1
Shadow trafficRunning a candidate on live inputs without serving its output4.2
LLM-as-judgeA model grading outputs against a rubric; checked against human labels4.3
Position, verbosity, self-preference biasA judge favouring an answer’s place, its length, or its own model4.3
Judge driftA judge’s agreement with human labels falling over time4.3
Paired differenceComparing two configurations on the same cases, which removes case difficulty from the noise4.4
Power analysisChoosing cases and runs to detect the effect size that matters4.4
Regression caseA past failure added to the suite so it can’t come back unnoticed4.5
