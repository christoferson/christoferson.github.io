When to refresh

Triggers

  • A new guide version in the Skilljar version picker, or a Pearson VUE content-update notice for CCAR-P.
  • New models, price changes, or deprecation and retirement dates on the models and deprecations pages.
  • Changes to rate limits, prompt caching rules, context management tools, or data retention and residency (ZDR, HIPAA, inference_geo).
  • Claude Code releases that change permission modes, plugins, managed settings or Code Review.
  • A new MCP specification revision, or a new Usage Policy version.
