Often confused pairs

PairThe difference
CloudTrail and ConfigWho called the API versus what the resource looked like
Metric filter and subscription filterTurns log lines into a metric versus streams log events to Lambda, Kinesis, Firehose or another account
Composite alarm and metric math alarmCombines alarm states versus calculates one metric from several
Instance refresh and rolling update policyAuto Scaling feature versus CloudFormation UpdatePolicy (which can trigger a refresh)
Lifecycle hook and warm poolPauses an instance during launch or termination versus keeps pre-initialized instances ready
Read replica and Multi-AZ standbyScales reads, asynchronous versus provides failover, synchronous and not readable (instance deployment)
Backtrack and point-in-time restoreRewinds the same Aurora MySQL cluster in place versus creates a new database
Deprecate, disable and deregister an AMIHidden but launchable versus can't be launched versus deleted
Run Command and State ManagerOnce now versus continuously on a schedule
SCP and permissions boundaryCaps a whole account from the organization versus caps one user or role
SCP and RCPLimits what principals can do versus limits who can access resources
Secrets Manager and Parameter StoreRotation and replication versus cheaper configuration storage
Alias and CNAMEWorks at the apex, free for AWS targets, no TTL versus not at the apex, charged
Latency and geolocation routingFastest Region for the user versus Region chosen by the user's location
CloudFront and Global AcceleratorCaches HTTP content versus accelerates any TCP or UDP with static IPs
Cache policy and origin request policyWhat forms the cache key versus what is forwarded without affecting the key
Inbound and outbound Resolver endpointsOn premises asking AWS versus AWS asking on premises
Gateway and interface endpointsFree route-table entry for S3 and DynamoDB versus paid network interface for most services
