AWS Certified CloudOps Engineer – Associate

Running workloads on AWS day to day: monitoring and fixing them, keeping them available and recoverable, deploying and automating them, securing them, and connecting them over the network. Formerly AWS Certified SysOps Administrator – Associate; the exam code stays SOA.

How to use this guide

The exam is for engineers with about a year of hands-on AWS operations experience. It tests configuring, operating and troubleshooting, not designing architectures or pipelines.

  1. Start with Domains 1 and 3Monitoring and automation underpin everything else: how you notice problems and how you fix them without logging in.
  2. Then Domains 2 and 5Scaling, high availability, backup and disaster recovery, then VPC, DNS and content delivery, where many troubleshooting questions sit.
  3. Finish with Domain 4IAM, multi-account controls, encryption and security findings.
