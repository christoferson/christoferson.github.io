The exam

KCNA at a glance
Format
Online, proctored, multiple choice: 60 questions in 90 minutes, taken through PSI
Passing score
75%; results within 24 hours
Cost and validity
US$250 including one free retake; 12 months to take it; certification valid 2 years (renewed by passing CKA or CKAD)
Level
Beginner; no prerequisites

ClueAnswer
Cluster + user + namespace under one nameA kubeconfig context (kubectl)

Scheduling (Topic 1.3)

ClueAnswer
How the scheduler picks a nodeFilter, score, bind (scheduler)
What the scheduler uses for placementRequests, not limits or actual usage (resources)

Pod must run on SSD-labelled nodesnodeSelector or required node affinity (node selection)
Keep replicas on different nodes or zonesPod anti-affinity or topology spread constraints
Keep Pods off a node unless allowedTaint the node; tolerate in the Pod (taints)

Pod stays Pending with FailedSchedulingNo feasible node: check resources, taints, affinity

Domain 2: Container Orchestration

Networking (Topic 2.1)

ClueAnswer
Gives every Pod an IP and connects nodesA CNI plugin (CNI)
Stable internal address for a set of PodsService of type ClusterIP (Services)
Port 30000–32767 on every nodeNodePort
DNS returns Pod IPs, no virtual IPHeadless Service (clusterIP: None)
Programs Service routing on nodeskube-proxy: iptables (default), nftables, ipvs deprecated (kube-proxy)
Service DNS namesvc.ns.svc.cluster.local; CoreDNS (DNS)
Role-oriented successor to IngressGateway API: GatewayClass, Gateway, HTTPRoute (Gateway API)
Allow only frontend to reach the APINetworkPolicy; needs a plugin that enforces it (NetworkPolicy)
mTLS and retries without code changesService mesh, sidecar or sidecarless (mesh)

ClueAnswer

Avoid: node files mounted into a PodhostPath; use a local PV
