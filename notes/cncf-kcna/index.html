Study notes for the Kubernetes and Cloud Native Associate

How to use this guide

KCNA is an entry-level exam with no prerequisites, for developers and non-developers alike. The official curriculum is short: four weighted domains, each with a few topic names. These notes take each topic in turn, explain what it covers using the Kubernetes documentation and CNCF sources, and show real kubectl commands and YAML manifests, all against Kubernetes v1.37.

  1. Start with Domain 1Nearly half the exam: what a cluster is made of, how it is run, how Pods are placed on nodes, and what containers are.
  2. Then Domain 2Running containers at scale: networking, security, storage, and finding out what went wrong.
  3. Then Domains 3 and 4Getting applications into a cluster and debugging them, then observability and the cloud native ecosystem and community.

About the exam in 2026. KCNA is an online, proctored, multiple-choice exam taken through PSI: 60 questions in 90 minutes, with 75% needed to pass. It costs US$250 including one free retake, and the certification is valid for two years. The curriculum was revised in November 2025: the old Observability domain was folded into Cloud Native Architecture and application delivery doubled in weight, so courses written before then follow an older outline.
