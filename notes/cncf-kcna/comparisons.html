Workload resources

Domain 1: Kubernetes Fundamentals. See topic 1.1.

ResourceRunsChoose it for
DeploymentInterchangeable replicas; rolling updates and rollbacks through ReplicaSetsStateless apps such as a web frontend or API
ReplicaSetA stable number of identical PodsRarely directly: Deployments create and manage them
StatefulSetPods with stable names, ordered start-up and their own PVC eachDatabases and other apps that keep identity and data
DaemonSetOne Pod on every (or every matching) nodeLog collectors, node monitoring, network agents
JobPods that run to completion, retried on failure (backoffLimit 6)One-off tasks such as a data migration
CronJobJobs on a repeating scheduleNightly reports, backups

Often confused pairs

Short distinctions that exam questions like to test.

PairDifferenceSee
Pod phase and CrashLoopBackOffPhases are Pending, Running, Succeeded, Failed, Unknown; CrashLoopBackOff is a kubectl status for repeated crashesTopic 1.1
Deployment and ReplicaSetA Deployment manages ReplicaSets, which manage the Pods; do not manage a Deployment's ReplicaSets yourselfTopic 1.1
Requests and limitsThe scheduler uses requests; the kubelet enforces limits (CPU throttled, memory OOM-killed)Topic 1.3
Taint and tolerationA taint on a node repels; a toleration on a Pod permits but does not attractTopic 1.3
RWO and RWOPRWO is one node, possibly several Pods; RWOP is exactly one PodTopic 2.4
Ingress API and Ingress NGINXThe API is frozen but stays; the Ingress NGINX controller was retired in March 2026Topic 2.1
Liveness and readiness failureLiveness failure restarts the container; readiness failure only removes it from Service endpointsTopic 3.2
/lgtm and /approveReviewers say /lgtm (looks good); approvers say /approve (accept the change)Topic 4.3
CLA and DCOKubernetes requires the CNCF CLA; many CNCF projects use only a DCO sign-off per commitTopic 4.3
Cluster operator and Operator patternA cluster operator is a person running clusters; an Operator is a controller for custom resourcesTopic 4.3
Certified Kubernetes and graduated projectCertification means a vendor product passed conformance; graduation is a TOC decision on project maturityTopic 4.2
Landscape listing and CNCF projectThe Landscape lists products from everywhere; only projects with a CNCF stage are hosted by the CNCFTopic 4.2
Continuous delivery and continuous deploymentDelivery stops at an acceptance environment; deployment goes to production automaticallyTopic 3.1
Monitoring and observabilityMonitoring watches known problems; observability lets you investigate unknown onesTopic 4.1
OpenTracing, OpenCensus and OpenTelemetryThe first two merged into OpenTelemetry and are archived; OpenTelemetry graduated in May 2026Topic 4.1
Cloud Native Definition v1.0 and v1.1v1.0 (2018) says technologies; v1.1 (2024) says practices and adds secure, sustainable, multi-tenancy and serverlessTopic 4.2
Secret encoding and encryptionSecret values are base64-encoded, not encrypted; etcd stores them unencrypted unless encryption at rest is configuredTopic 2.2
