Overview

A quick lookup for the vocabulary of the KCNA exam. Meanings are short summaries in our own words or brief quotes from the Kubernetes glossary (© The Kubernetes Authors, CC BY 4.0); the topic pages give the full detail and sources. Project statuses come from the CNCF Landscape and project pages in November 2026 and change often.

Architecture components

ReferenceThe parts of a cluster and what each does.

Control plane and node components, from topic 1.1 onwards.

TermMeaningCovered in
ClusterA control plane plus worker machines (nodes) that run containerized applications1.1
Control planeComponents that make "global decisions about the cluster" and respond to events1.1
kube-apiserver"The front end for the Kubernetes control plane"; every component talks through it1.1
etcdKey-value store, the "backing store for all cluster data"; back it up1.1, 1.2
kube-schedulerPicks a node for each new Pod: filtering, scoring, binding1.1, 1.3
kube-controller-managerRuns the built-in controllers in one binary1.1
cloud-controller-managerOptional; cloud-specific logic such as load balancers1.1
NodeA virtual or physical machine that runs Pods1.1
kubelet"An agent that runs on each node"; makes sure containers are running in Pods1.1
kube-proxyOptional node component that implements Service routing (iptables, nftables)1.1, 2.1
Container runtimeRuns containers through the CRI, for example containerd or CRI-O1.4
ControllerA control loop that moves current state towards desired state1.1
Static PodA Pod managed directly by the kubelet from a manifest file; kubeadm runs the control plane this way2.3
Add-onCluster feature built from Kubernetes resources: CNI plugin, CoreDNS, metrics-server1.2
LeaseSmall object in kube-node-lease used for node heartbeats1.1, 2.3

Workload objects

ReferenceThe objects that run and scale applications.

Pods and the workload resources that manage them.

TermMeaningCovered in
Pod"The smallest deployable units of computing"; one or more containers sharing network and storage1.1
Init containerRuns to completion before the app containers start1.1, 3.2
Sidecar containerAn init container with restartPolicy: Always that keeps running; stable since v1.331.1
Ephemeral containerTemporary debugging container added to a running Pod1.1, 3.2
ReplicaSetKeeps a stable number of identical Pods running; usually created by a Deployment1.1
DeploymentStateless apps with rolling updates and rollbacks; manages ReplicaSets1.1, 3.1
StatefulSetPods with stable names, ordered rollout and their own storage1.1, 2.4
DaemonSetOne Pod on every (or selected) node1.1
JobPods that run a task to completion; retried up to backoffLimit1.1, 3.2
CronJobJobs on a schedule1.1
HorizontalPodAutoscalerChanges the replica count to match a metric4.2
PodDisruptionBudgetLimits how many Pods may be down at once during voluntary disruptions1.2
PriorityClassGives Pods a priority used for scheduling order and preemption1.3

Networking objects

ReferenceThe objects that connect and expose Pods.

Services, routing and policy.

TermMeaningCovered in
ServiceA stable address and name for a set of Pods; types ClusterIP, NodePort, LoadBalancer, ExternalName2.1
Headless ServiceclusterIP: None; DNS returns Pod IPs directly2.1
EndpointSliceLists the Pods behind a Service; replaces the deprecated Endpoints API2.1, 2.3
IngressHTTP(S) routing into the cluster; needs an Ingress controller; API frozen2.1
Gateway, HTTPRouteGateway API resources for role-oriented traffic routing; installed as CRDs2.1
NetworkPolicyAllow rules for Pod traffic; enforced only by a supporting network plugin2.1
CoreDNSThe cluster DNS server; its Service is still called kube-dns2.1

Storage objects

ReferenceThe objects that give Pods data that lasts.

Volumes, claims and classes.

TermMeaningCovered in
VolumeA directory available to a Pod's containers; ephemeral or persistent2.4
emptyDirScratch space that lives as long as the Pod stays on its node2.4
PersistentVolume (PV)A cluster-wide piece of storage, provisioned statically or dynamically2.4
PersistentVolumeClaim (PVC)A namespaced request for storage, bound to one PV2.4
StorageClassDescribes a kind of storage and creates PVs on demand2.4
VolumeSnapshotA point-in-time copy of a volume; CRDs plus a snapshot controller2.4

Security and access objects

ReferenceThe objects that control identity, permissions and Pod privileges.

Authentication, RBAC, admission and Pod security.

TermMeaningCovered in
ServiceAccountA namespaced identity for workloads, with short-lived tokens2.2
Role, ClusterRoleSets of RBAC permissions, in one namespace or cluster-wide2.2
RoleBinding, ClusterRoleBindingGrant a Role or ClusterRole to users, groups or ServiceAccounts2.2
Admission controllerMutates or validates requests after authorization, before storage2.2
Pod Security StandardsPrivileged, Baseline and Restricted levels, enforced per namespace by Pod Security Admission2.2
securityContextPer-Pod or per-container user, privilege and kernel settings2.2
SecretSmall sensitive data; base64-encoded and unencrypted in etcd by default1.1, 2.2

Configuration and organization

ReferenceThe objects that organize and configure everything else.

Namespaces, labels, settings and limits.

TermMeaningCovered in
NamespaceIsolates groups of names; four exist at start1.1
Label, selectorKey/value tags that identify objects, and queries that select them1.1
AnnotationNon-identifying metadata, never used for selection1.1
ConfigMapNon-confidential configuration as key-value pairs1.1
ResourceQuotaCaps a namespace's total resource use and object counts1.2
LimitRangePer-container minimums, maximums and defaults1.2
kubeconfig, contextClient configuration; a context is a cluster plus user plus namespace1.2

Extensibility

ReferenceHow Kubernetes is extended and switched.

Custom resources, operators and feature switches.

TermMeaningCovered in
CustomResourceDefinition (CRD)Adds a new resource type to the API without programming1.2
OperatorSoftware that uses custom resources and a control loop to manage an application1.2, 4.2
Feature gateSwitches a feature on or off; alpha off, beta usually on, GA always on1.2
RuntimeClassSelects a container runtime handler, such as a sandbox1.4
KYAMLA stricter YAML subset for Kubernetes; kubectl -o kyaml stable in v1.371.1
