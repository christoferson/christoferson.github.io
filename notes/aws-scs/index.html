AWS Certified Security – Specialty

Securing workloads on AWS: detecting threats and anomalies, logging and monitoring at organization scale, responding to incidents, controlling network edges, compute and networks, managing identities and permissions, protecting data with encryption, secrets and keys, and governing accounts, deployments and compliance.

How to use this guide

The exam is for people responsible for securing cloud solutions, with the equivalent of three to five years of experience doing so. Questions describe a requirement or a security event and ask for the control, service or response that meets it, often weighing cost, security and deployment complexity. Each task page explains every skill in the official exam guide, with one running example, configuration and code, exam tips and common traps. Basics already taught in the Solutions Architect guide are summarized and linked rather than repeated.

  1. Start with Domains 4 and 5Identity and access management and data protection are 38% of the exam together: policies and their evaluation, federation, KMS, certificates and secrets.
  2. Then Domains 1 and 2Detection and incident response: what to log and where, how findings are raised and aggregated, and how to contain, investigate and recover.
  3. Then Domains 3 and 6Infrastructure controls at the edge, on compute and in the network, then multi-account governance, secure deployment and compliance.

About the exam in 2026. SCS-C03 replaced SCS-C02 on 2 December 2025. It has 65 questions in 170 minutes, 50 scored and 15 unscored and not identified. Besides multiple choice and multiple response, it uses ordering items (put 3 to 5 steps in order) and matching items (match 3 to 7 prompts); both are scored only when fully correct. The passing score is 750 on a scale of 100 to 1,000, the fee is US$300, and the certification is valid for three years. The current exam guide is version 1.0, published on 26 March 2026. The Simplified Chinese, Spanish (Latin America) and Portuguese (Brazil) versions retire after 31 December 2026.

Changed services. Some services the guide names have changed. The original AWS Security Hub is now AWS Security Hub CSPM, alongside a newer Security Hub. AWS Audit Manager is moving to maintenance mode and can't be set up in new accounts from 30 April 2026. AWS CloudTrail Lake closed to new customers on 31 May 2026. Amazon Q Business is closed to new customers (Amazon Quick is the suggested path), and Amazon Q Developer IDE plugins reach end of support on 30 April 2027. Amazon CodeGuru Security is no longer in the AWS documentation; code scanning is taught with Amazon Inspector code security. The task pages teach the current services and say where the guide's names differ.
