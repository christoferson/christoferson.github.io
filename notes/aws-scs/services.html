Overview

The exam guide (version 1.0) lists about 70 services and features in ten categories; a few VPC features are listed as sub-items, and Network Access Analyzer and VPC endpoints appear twice. The list isn't exhaustive, and the guide adds an important note: security affects every AWS service, so a service can be out of scope while its security settings are in scope (you won't be asked how to set up S3 replication, but you may be asked about a bucket policy). It also lists technologies that may appear: the AWS CLI, SDKs and Management Console, secure remote access, certificate management and infrastructure as code.

Each entry says what the service is for on this exam and links to the task sections that explain it. Background means the notes only mention it: know in one sentence what it does. The cheat sheet maps question clues to services, and the comparisons page sets similar options side by side.

Analytics

  • Amazon Athena: SQL over CloudTrail, flow logs, ALB logs and Security Lake in S3; partition projection keeps queries fast and cheap. 1.2, 2.2, 2.2
  • Amazon OpenSearch Service: log search and dashboards, a Security Lake subscriber and a Firehose destination; fine-grained access control, encryption and TLS policies. 1.2, 1.2, 5.1

Application integration

  • Amazon SNS: alarm and finding notifications; topic policies and a CMK when EventBridge publishes to an encrypted topic. 1.3, 6.3, 5.3
  • AWS Step Functions: multi-step incident response workflows, with waitForTaskToken for human approval. 2.1

Compute

  • Amazon API Gateway: access and execution logging, the account CloudWatch role, WAF, resource policies, TLS policies and mTLS. 1.3, 3.1, 5.1
  • Amazon EC2: IMDSv2, instance profiles, Allowed AMIs, evidence capture and isolation, Nitro encryption in transit. 3.2, 3.2, 2.2, 2.2, 5.1
  • EC2 Image Builder: hardened golden AMIs with STIG, CIS and SCAP components and Inspector scans in the pipeline. 3.2
  • EC2 Instance Connect: short-lived SSH keys, and the EIC Endpoint for private instances without bastions. 3.2
  • Amazon EKS: Pod Identity and IRSA, audit logs, GuardDuty runtime monitoring, network policies, encryption options. 3.2, 1.1, 2.2, 5.1
  • Amazon EMR: security configurations for at-rest and in-transit encryption. 5.1
  • AWS Lambda: remediation functions, logging configuration, execution roles, code signing, secrets retrieval. 1.3, 2.1, 5.2, 5.3
  • Amazon Data Lifecycle Manager: scheduled EBS snapshot and AMI policies, with cross-Region and cross-account copies. 5.2, 5.2

Developer tools

  • AWS Fault Injection Service: experiments that test detection and response, with stop conditions. 2.1

Internet of Things

  • AWS IoT Core: X.509 device certificates, IoT policies with policy variables, and Device Defender audits. 3.1

Machine learning

  • Amazon Bedrock: Guardrails (content filters, denied topics, sensitive information filters), the bedrock:GuardrailIdentifier condition and the ApplyGuardrail API. 3.2, 5.3
  • Amazon CodeGuru Security: named in the guide but no longer in the AWS documentation; its job is now done by Amazon Inspector code security and Amazon Q Developer code reviews. 3.2
  • Amazon Q Business: an enterprise assistant over company data; closed to new customers, with Amazon Quick as the alternative. Background.
  • Amazon Q Developer: code reviews and security scans in the IDE; the IDE plugins reach end of support on 30 April 2027. 3.2
  • Amazon SageMaker AI: notebooks for investigation, inter-container traffic encryption, network isolation. 2.1, 5.1

Management and governance

  • AWS CloudFormation: StackSets across accounts, stack policies, service roles, Guard and Lambda hooks, dynamic references for secrets. 6.2, 6.1
  • AWS CloudTrail: organization trails, data and network activity events, advanced event selectors, log file validation, the first source in an investigation. 1.2, 1.3, 2.2
  • AWS CloudTrail Lake: SQL over event data stores; closed to new customers since 31 May 2026. 1.2
  • Amazon CloudWatch: metric filters and alarms, Logs Insights, centralization rules, data protection masking, subscription filters. 1.1, 1.2, 1.2, 1.3
  • AWS Config: recording, managed and custom rules, conformance packs, aggregators, remediation with Systems Manager Automation. 6.3, 1.1, 1.3
  • AWS Control Tower: landing zones, preventive, detective and proactive controls, account enrollment, customizations. 6.1
  • Amazon Managed Grafana: security dashboards over CloudWatch, OpenSearch and Athena. 1.2
  • AWS Organizations: OUs, SCPs, RCPs, declarative and management policies, delegated administrators, centralized root access. 6.1, 6.1, 6.1, 6.1
  • AWS Resilience Hub: resilience assessments, one of the ways to test response plans. 2.1
  • AWS Resource Access Manager: share subnets, Resolver rules, Private CA and more without copying credentials; managed permissions. 6.2
  • AWS Service Catalog: approved products with launch constraints so users don't need resource permissions; portfolio sharing. 6.2
  • AWS Systems Manager: Session Manager, Patch Manager, Automation runbooks, OpsCenter, State Manager, Parameter Store. 3.2, 3.2, 2.1, 6.3
  • AWS Trusted Advisor: automated security checks; the full set needs Business Support+, Enterprise or Unified Operations. 6.3
  • AWS User Notifications: email and chat notifications for AWS events, used for example by AWS Artifact. 6.3
  • AWS Well-Architected Tool: question-based reviews against the Security pillar, lenses, milestones. 6.3

Networking and content delivery

  • Amazon Application Recovery Controller (ARC): routing controls, zonal shift and Region switch for recovery. 2.1
  • Amazon VPC: security groups and network ACLs, Block Public Access, flow logs, VPC endpoints and endpoint policies, Site-to-Site VPN, Verified Access. 3.3, 3.3, 1.2, 5.1
  • Network Access Analyzer: finds unintended network paths against a scope you define. 3.3
  • AWS Site-to-Site VPN: IPsec tunnels and their options, also over Direct Connect. 3.3
  • AWS Verified Access: VPN-less access to private applications with Cedar policies on identity and device posture. 3.3, 5.1
  • AWS Client VPN: managed remote-access VPN with certificate, Active Directory or SAML authentication. 3.3
  • Amazon CloudFront: origin access control, VPC origins, security headers, signed URLs, TLS policies. 3.1, 3.1, 5.1
  • Amazon Verified Permissions: fine-grained application authorization with Cedar (listed under networking in the guide). 4.2
  • Amazon Route 53: query logging, Resolver DNS Firewall, health checks. 1.2, 3.3, 1.1
  • AWS Direct Connect: private connectivity, MACsec encryption, VPN over Direct Connect. 3.3
  • Elastic Load Balancing: TLS security policies (post-quantum), ALB mutual TLS, access logs, WAF on ALBs. 5.1, 3.1, 1.2
  • AWS Transit Gateway: segmentation with route tables, inspection VPCs, flow logs. 3.3, 3.3, 1.2

Security, identity and compliance

  • AWS Artifact: AWS's own compliance reports and agreements, such as the HIPAA BAA. 6.3
  • AWS Audit Manager: evidence collection for frameworks; maintenance mode, not available to new accounts from 30 April 2026. 6.3
  • AWS Certificate Manager: public and private certificates, managed renewal, expiry events, Regional certificates. 5.3, 5.1
  • AWS CloudHSM: single-tenant HSMs you control (hsm2m.medium), custom key stores. 5.2, 5.3
  • Amazon Cognito: user pools with MFA and threat protection, identity pools for AWS credentials. 4.1, 4.1
  • Amazon Detective: behavior graphs for root cause analysis and scoping. 2.2, 1.1
  • AWS Directory Service: AWS Managed Microsoft AD and AD Connector as identity sources. 4.1, 4.1
  • AWS Firewall Manager: WAF, Shield Advanced, security group, network ACL and Network Firewall policies across the organization. 6.2, 3.1, 3.3
  • Automated Forensics Orchestrator for Amazon EC2: automated evidence capture; now published as AWS guidance for EC2 and EKS. 2.1, 2.2
  • Amazon GuardDuty: threat detection from logs and runtime agents, protection plans, suppression rules, organization enablement. 1.1, 3.2, 2.2
  • AWS Identity and Access Management (IAM): policy evaluation, roles and trust policies, permissions boundaries, ABAC, Access Analyzer. 4.2, 4.2, 4.1
  • AWS IAM Identity Center: workforce sign-in, identity sources and SCIM, permission sets, MFA. 4.1, 4.2
  • Amazon Inspector: vulnerability scanning of EC2, ECR and Lambda, code security, CIS scans, SBOM export. 3.2, 3.2
  • AWS Key Management Service (KMS): key types and policies, grants, envelope encryption, imported material, multi-Region keys, external key stores. 5.2, 5.3, 5.3
  • Amazon Macie: sensitive data discovery in S3. 1.1, 5.3
  • AWS Network Firewall: stateful and stateless rules, domain lists, Suricata rules, TLS inspection. 3.3
  • AWS Private Certificate Authority: private CA hierarchies, modes and revocation for internal TLS and mTLS. 5.3, 5.1
  • AWS Secrets Manager: secret rotation, cross-account access, replicas, the Workload Credentials Provider. 5.3
  • AWS Security Hub: Security Hub CSPM (standards, controls, ASFF, automation rules) and the newer Security Hub that correlates findings. 1.1, 6.3
  • Amazon Security Lake: an OCSF security data lake in the log archive account, with subscribers and custom sources. 1.2, 1.1
  • AWS Shield: Standard is automatic layer 3 and 4 protection for every customer. 3.1
  • AWS Shield Advanced: protection groups, health-based detection, the Shield Response Team, cost protection. 2.1, 3.1
  • AWS Security Token Service (STS): temporary credentials, AssumeRole variants, Regional endpoints, session revocation. 4.1, 2.2
  • AWS WAF: managed and custom rules, rate-based rules, Bot Control, fraud prevention, logging. 3.1, 3.1, 3.1

Storage and data management

  • Amazon S3: bucket policies, Block Public Access, encryption options, Object Lock, replication, presigned URLs. 5.2, 5.2, 5.1, 1.2
  • AWS Backup: backup plans and policies, vault lock and access policies, logically air-gapped vaults. 5.2, 2.2
  • AWS DataSync: encrypted transfers with integrity verification. 5.2, 5.2
  • Amazon EFS: encryption at rest and in transit, lifecycle policies. 5.2, 5.2
  • Amazon FSx for Lustre: encryption and backups. 5.2

Also used in these notes

Not on the in-scope list, but the notes rely on them because questions use them to deliver a security outcome:

  • Amazon EventBridge: routes findings, compliance changes and API events to responders; a central security event bus. 1.1, 2.1, 1.3
  • IAM Access Analyzer (part of IAM): external, internal and unused access findings, policy generation and checks. 4.2, 3.3
  • IAM Roles Anywhere: temporary credentials for on-premises workloads with X.509 certificates. 4.1, 4.2
  • AWS Security Incident Response: AWS's incident response service with case management and responders. 2.1
  • AWS Health: account-specific events, including exposed credential notices. 1.1
  • Amazon ECR and Amazon ECS: image scanning, immutability and signing; task and execution roles. 3.2, 3.2
  • Amazon Data Firehose: delivers logs to S3, OpenSearch and partner tools. 1.2
  • AWS Lake Formation, AWS Glue and Amazon Comprehend: fine-grained data lake access and sensitive data detection. 5.3
  • Amazon VPC Lattice and AWS Cloud WAN: service-to-service auth policies and global network segmentation. 3.3, 5.1
  • AWS Global Accelerator: edge entry point protected by Shield Standard, with no layer 7 protection. 3.1
  • AWS Signer: code signing for Lambda. 5.2
  • AWS Resource Groups: tag- and stack-based groups for operations. 6.2

Renamed services

Old names still appear in questions, blog posts and the guide itself. Same service, new name:

  • AWS Security Hub (the posture checks) is now AWS Security Hub CSPM; the name Security Hub now belongs to the newer findings service.
  • Route 53 Application Recovery Controller is now Amazon Application Recovery Controller (ARC).
  • AWS Single Sign-On (AWS SSO) is now AWS IAM Identity Center.
  • Amazon SageMaker is now Amazon SageMaker AI.
  • The Secrets Manager Agent is now the AWS Workload Credentials Provider.
  • Automated Forensics Orchestrator for Amazon EC2 is now published as AWS guidance for EC2 and EKS forensics.
  • The Amazon Q Developer console chat is now the AWS assistant; Q Developer in the IDE and command line keeps its name.
  • The new AWS WAF console calls web ACLs protection packs; they're the same web ACLs in the API.
  • In Control Tower landing zone 4.0 the log archive and audit accounts are the CloudTrail administrator and Config aggregator accounts.
  • The Service Catalog Terraform Open Source product type is now External.

Out of scope

The guide lists only two services as out of scope, verbatim, and says the list isn't exhaustive:

  • Application Integration: Amazon Managed Workflows for Apache Airflow (Amazon MWAA)
  • Security, Identity, and Compliance: AWS Payment Cryptography

Out of the list isn't out of the exam. Because security applies to every service, the security settings of services missing from the in-scope list (RDS encryption, DynamoDB backups, ECR scanning, EventBridge rules) still appear in questions. The task pages cover them where they matter.
