Often confused pairs

  • GuardDuty suppression rule and trusted IP list: Archives matching findings as they arrive (they then skip Security Hub CSPM, Detective and EventBridge) versus not generating findings for listed IPs at all.
  • Security group and network ACL: Stateful allow-only filter on an interface, where tracked connections survive a rule change, versus stateless allow-and-deny filter on a subnet that cuts connections immediately.
  • Config rule and Config remediation: Reports compliance versus fixes it; a rule never remediates unless a remediation configuration with an SSM Automation runbook is attached.
  • Config aggregator and organization conformance pack: A read-only view of compliance across accounts versus a deployment of rules and remediation to every account.
  • Control Tower proactive control and Config proactive evaluation: A CloudFormation hook that can block a deployment versus an evaluation that only reports.
  • AWS Artifact and Audit Manager: AWS's own audit reports and agreements versus evidence of your own controls (Audit Manager is closed to new accounts).
  • SCP and permissions boundary: Caps every principal in member accounts, never the management account, versus caps one IAM user or role.
  • AWS managed key and customer managed key: Created by AWS with a fixed key policy and no cross-account use versus your own key policy, grants, rotation settings and cross-account sharing.
  • Deactivating an access key and revoking role sessions: Stops a long-term key, including presigned URLs signed with it, versus denying temporary credentials issued before a set time with AWSRevokeOlderSessions.
  • Key rotation and key deactivation: New key material for future encryption, with old data still decryptable, versus stopping all use; rotation is not containment.
  • Secrets Manager and Parameter Store SecureString: Managed rotation, cross-account resource policies and replication versus encrypted parameters without managed rotation.
  • CloudTrail management events and data events: Control-plane calls, logged by trails by default, versus object and function-level calls (S3 GetObject, Lambda Invoke), off by default and charged extra.
  • Network Access Analyzer and Reachability Analyzer: Finds every path that breaks your intent versus explains whether one specific path works.
  • Shield Standard and Shield Advanced: Free automatic layer 3 and 4 protection versus a subscription with the Shield Response Team, application-layer mitigation and cost protection.
  • RAM resource share and shared VPC: Shares a resource with other accounts versus participants launching their own resources into the owner's shared subnets without control of the network.
