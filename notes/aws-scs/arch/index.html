Grouped by theme, using the same company and accounts as the task pages. Each page stands alone. See also the official blogs and references.

Foundation and governance

  • Multi-account security baseline (AWS Security Reference Architecture): OUs and Control Tower, delegated administrators in the security tooling account, SCPs, RCPs and declarative policies, and centralized root access.
  • Data perimeter across the organization: Only trusted identities, reaching trusted resources, from expected networks: SCPs, RCPs and VPC endpoint policies working together.

Detection and response

  • Centralized threat detection and automated response: GuardDuty, Security Hub and Detective run from one delegated administrator, with EventBridge and automation runbooks acting on findings.
  • Incident response and forensics: A forensics account and OU, isolating a compromised workload, capturing disk and memory evidence, and the AWS Security Incident Response service.
  • Security logging and the security data lake: An organization trail, centralized CloudWatch Logs, Security Lake in OCSF, Athena queries and an immutable archive in the log archive account.

Identity

  • Workforce identity and temporary elevated access: IAM Identity Center with an external identity provider, permission sets, attribute-based access and just-in-time elevation with audit.

Data protection and workloads

  • Encryption and key management at scale: A KMS key hierarchy across accounts and Regions, key policies and grants, multi-Region keys, external key stores and secrets rotation.
  • Ransomware resilience and data recovery: AWS Backup vault lock, logically air-gapped vaults, S3 Object Lock and Recycle Bin, with restores into a clean account.
  • Container and EKS workload security: Pod Identity, image scanning and signing, GuardDuty Runtime Monitoring, network policies and IMDSv2 for the container platform.
  • Secure CI/CD and governance as code: Inspector code security, CloudFormation Guard and hooks, StackSets and conformance packs keeping every deployment inside the guardrails.
