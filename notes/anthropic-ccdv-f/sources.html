When to refresh

Triggers

  • A new guide version in the Skilljar version picker, or a Pearson VUE content-update notice for CCDV-F.
  • A beta used on these pages becomes generally available or changes its header: Managed Agents, compaction, context editing, the MCP connector.
  • New models, price changes, or changes to which models reject forced tool_choice.
  • New major versions of the anthropic SDK, the Agent SDK or the MCP Python SDK.
