All four are delivered by Pearson VUE (online or at a test center), are valid for 12 months, have no formal prerequisites, and can only be booked by people at Claude Partner Network organizations. The certifications page singles out only the Associate as not counting toward partner tier eligibility, and suggests starting at Foundations and moving to Professional where available.

Who each exam is for

The four guides place their candidates on one line. The Associate guide puts its candidate between casual prompt users and technical practitioners; the Developer builds the applications; the two Architect exams design them, the Professional one for whole organizations. Each guide describes its audience in three parts: what holders can show, who typically sits the exam, and who it isn't meant for.

Associate – Foundations

For people who use Claude as an everyday productivity tool and build Claude Projects, in operations, marketing, project management, education, communications and general knowledge work. The guide names two groups: staff who run and improve AI-enabled workflows inside an organization, and outside consultants who help with implementation, finding use cases and redesigning processes. What sets them apart is turning a business goal into a good Claude interaction, picking the right feature, structuring the prompt, reading the result critically, adapting it for an audience, and knowing when a person must check it or take over.

Holders can show that they can:

  • complete structured business tasks with Claude with little guidance;
  • use Claude's built-in features and tools to streamline workflows;
  • spot where Claude can improve a process;
  • choose approaches that balance quality, efficiency and cost;
  • recognise Claude's limits and escalate complex or technical work.

Not for software developers who build against APIs or design agentic systems, or specialists in machine learning, software engineering or advanced AI design. Enterprise-scale architecture and integrations belong to the Architect and Developer credentials, and Associates hand that work to them.

Developer – Foundations

For technical professionals who build, integrate and ship production-grade applications on Claude, mainly AI and machine learning engineers, technical leads and senior software engineers who work where business requirements meet implementation. The holder can own, or contribute much of, a Claude-powered system on their own, turning technical requirements into working code and weighing trade-offs in model choice (cost, latency, capability) and tool type (built-in tools, custom tools, Skills, MCP servers).

Holders can show that they can:

  • build agents and workflows with the Claude Agent SDK, agent frameworks and custom agent loops;
  • integrate Claude into application code through the API, client SDKs and third-party integrations, including streaming, error handling and inputs in several formats;
  • run Claude Code from its different interfaces, write Skills, and configure CLAUDE.md, settings.json and plugins;
  • write prompts and use context engineering to control behaviour and stop context drift;
  • design and run evaluations, debug failures from traces, validate structured output and monitor production quality;
  • choose model tiers and manage tokens, caching and batch processing for cost and latency;
  • design securely and add guardrails through hooks against prompt injection and destructive actions;
  • build custom tools, function schemas and MCP servers.

Not for non-technical or casual users, people without hands-on software development experience, or roles limited to writing prompts without wider responsibility for the application.

Architect – Foundations

For a solution architect who designs and implements production applications with Claude, with six months or more of practice building with the API, Agent SDK, Claude Code and MCP and a grasp of what models can and can't do in production. Where the Developer guide stresses shipping code, this one stresses design decisions and their trade-offs inside agent systems.

The guide expects hands-on experience with:

  • agent applications on the Agent SDK: multi-agent orchestration, delegating to subagents, tool integration and lifecycle hooks;
  • configuring Claude Code for a team with CLAUDE.md files, Agent Skills, MCP servers and plan mode;
  • designing MCP tools and resources that connect to back-end systems;
  • prompts that give reliable structured output, with JSON schemas, few-shot examples and extraction patterns;
  • managing context across long documents, multi-turn conversations and handoffs between agents;
  • Claude in CI/CD pipelines for code review, test generation and pull request feedback;
  • escalation and reliability: error handling, human-in-the-loop workflows and self-evaluation.

Unlike the other three, this guide has no "not intended for" statement; instead it lists topics that are out of scope, such as streaming, vision, caching details, rate limits, pricing and cloud providers, which the Developer exam covers.

Architect – Professional

For mid- to senior-level solution architects, AI/ML engineers, technical leads and senior software engineers who own the whole life cycle of a Claude system, from discovery to deployment and operation. They turn business problems into scalable designs, advise clients or internal teams, lead architecture decisions, and take part in discussions with security, legal and executive stakeholders. The guide names financial services, healthcare, retail, technology, education and government as typical industries.

Holders can show that they can:

  • design and prototype AI solutions for real business problems;
  • choose models, architectures and API patterns for a use case;
  • apply prompt engineering and context strategies to guide behaviour;
  • integrate Claude into production systems with APIs, orchestration tools and data pipelines;
  • use evaluation, monitoring and observability to keep quality up;
  • build security, compliance and governance into the design;
  • work with other teams and explain architecture decisions.

Not for entry-level developers, casual users, people who haven't designed end-to-end AI systems, or roles that are purely non-technical or limited to tasks such as writing prompts.

What only each exam tests

Only the Associate

  • Claude's own app features: Projects, research mode, chat and artifacts, uploaded knowledge, and connectors such as Google Drive and Gmail.
  • Editing and adapting output for an audience, curating information and choosing output formats (artifacts, inline text, structured data).
  • Applying Claude to everyday knowledge work: research, planning, process optimization and redesigning existing workflows, and explaining Claude's value and limits to colleagues.
  • The heaviest weight on judging output (21%) and on governance and responsible use (15%) of any Foundations exam.

Only the Developer

  • API mechanics: streaming, vision, thinking, caching, cloud providers, the Batch API.
  • Software engineering: REST, JSON, asynchronous code, version control, code review and refactoring.
  • Model and cost engineering: tokens, effort, caching strategy, cost tracking.
  • Building MCP servers, and agents with frameworks such as Strands, LangGraph and PydanticAI.

Only the Architect – Foundations

  • Scenario-framed questions throughout, from a published set of six production scenarios.
  • Deep agent orchestration: agentic loops, coordinators and subagents, hooks, sessions, task decomposition.
  • Claude Code for teams and CI in depth (a fifth of the exam), and reliability topics such as error propagation and information provenance.

Only the Architect – Professional

  • Designing RAG pipelines (chunking, indexing, retrieval strategies) and choosing integration protocols.
  • Regulatory compliance (GDPR, HIPAA and FedRAMP are named), bias, fairness and transparency at system level.
  • Structured discovery, communicating architectural decisions, SLAs and documentation for stakeholders.

Is the Associate exam easier?

Not in any way the guides state. The Associate exam has the same format and scaled pass mark as the others: 60 items, 120 minutes, and 720 out of 1,000. Anthropic doesn't publish relative difficulty, and no guide calls one exam easier than another. What differs is the role and the kind of knowledge tested:

  • It needs no technical knowledge. No code, API, SDK, MCP servers or CI. That makes it more accessible to non-developers, and its fee is lower.
  • Its hard parts are judgement calls. Its largest domains ask whether an answer is accurate and complete, whether it contains hallucinations or bias, whether a person must review it, and whether a use is appropriate under policy, privacy and regulation. These are hard to get right and can't be looked up as facts.
  • It's broad. Seven domains span prompting, output review, product features, workflow design, configuration, governance and troubleshooting.

So a strong developer who is weak at reviewing output or applying privacy and policy rules could find the Associate exam harder than the Developer one, and the reverse is just as likely. The real difference between the exams is which things you need to know, not how hard each one is.

Which to take

  • You use Claude daily in business work and don't write code: Associate. It covers what you already do, at the depth of a skilled user; note that it doesn't count toward Partner Network tiers.
  • You write the application code, call the API and ship features: Developer.
  • You design agent systems and decide how tools, Claude Code and context fit together: Architect – Foundations.
  • You lead architecture, own governance and compliance, and advise stakeholders: Architect – Professional, typically after Foundations.
  • You do several of these: the Developer and Architect – Foundations exams overlap heavily on agents, tools, Claude Code and prompting. The Associate overlaps with both mainly on prompting, model choice and judging output.

In short

  • All four have the same format and pass mark (720), with 53 to 63 items in 120 minutes; fees are $99, $125, $125 and $175.
  • Associate: business users of the Claude apps; heaviest on judging output (21%), workflows (16%) and governance (15%); no code.
  • Developer: engineers; a third of the exam is the API and software engineering, plus models and cost.
  • Architect – Foundations: agent systems, Claude Code, tools and prompting, all scenario-based.
  • Architect – Professional: end-to-end design, RAG and integration, evaluation, governance and stakeholders.
  • "Easier" isn't a stated difference: the Associate exam needs no technical background, but its judgement-based content is demanding in its own way.
