API errors: fix or retry

Domain 2. What each class needs. Covered in skill 2.4.

StatusMeaningDo
400, 413Invalid or too large requestFix the request; don't retry
401, 403, 404Auth, permission, or not foundFix credentials or the ID
429Rate limit, or the spend capBack off and honour retry-after; the spend cap won't clear
500, 529, timeoutServer error, overloaded, timed outRetry with backoff (the SDK already retries twice)
200 with refusalThe model declinedNot an error class: rephrase legitimately or fall back
