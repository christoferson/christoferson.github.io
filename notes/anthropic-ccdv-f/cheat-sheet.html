The exam

CCDV-F at a glance
Version
Exam guide version 1.1 for the content that starts on 7 December 2026 (published 17 November 2026). Before 7 December, the current guide's objectives apply.
Format
From 7 December: 70 scenario-based multiple-choice items in 120 minutes, 60 scored and 10 unscored (not identified). Before then: 53 items.
Scoring
Scaled 100 to 1,000; pass at 720.
Cost, delivery, validity
US$125 per attempt; Pearson VUE, online or at a test center; valid for 12 months; Claude Partner Network organizations only.

Domain 1: Agents and Workflows

Architecture and runtime (1.1)

ClueAnswer
Known steps, costly mistakes, every step auditedWorkflow, not an agent; must-hold rules in code (workflow or agent)
Long-running, asynchronous agent, nothing to hostClaude Managed Agents (beta), cloud environment (Managed Agents)
Files must stay on our serversManaged Agents self-hosted sandbox; history and tool results still reach Anthropic (sandboxes)
Run the loop in our own containersSelf-hosted Agent SDK: subprocess per session, SessionStore, isolation, max_turns (self-hosting)

Agent SDK and hooks (1.2)

ClueAnswer
"Always run the tests" is sometimes skippedA Stop hook that blocks finishing until the tests pass, checking stop_hook_active (Stop hooks)
Subagent can use every toolNo tools list in its AgentDefinition, so it inherits all (definitions)
Hook never fires or deny is ignoredMatcher doesn't match the tool name, or output lacks hookSpecificOutput (hook defects)
Ledger entry must follow every refundWrite it inside the refund tool's execution, not as a separate tool (harness)

Pattern diagnosis (1.3)

ClueAnswer
Loop exits while the response still asks for a toolLoop termination: continue while stop_reason is tool_use (termination)
Subagent "can't find the file above"Isolation misapplied: write a self-contained brief (isolation)
Every session asks the same question againMemory: the memory tool (client-side, block path traversal) or a progress file (memory)

Domain 4: Eval, Testing, and Debugging

Evaluation design (4.1)

ClueAnswer
"The judge scored 94%"Meaningless until calibrated against human labels: agreement, kappa, false-pass rate (calibration)
Which grader?Code where possible, LLM judge for judgement (rubric, specific output, different model), people for labels (graders)
Overall score flat, cases brokeGate on case-level regressions, not the average (regression)

Failure-mode diagnosis (4.2)

ClueAnswer
"Claude forgot" on turn 3Check integration first: history not resent (integration or model)
Agent only suggests changesAsk for the action ("Change this...") or add a default-to-action instruction (recoveries)
"Lower the temperature" for inconsistencyRejected under API 2026-10-21; use format, examples, retrieval, chaining (symptom fixes)

Domain 5: Model Selection and Optimization

Generation mechanics (5.1)

ClueAnswer
Same text, more tokens on the new model4.7 and later tokenise about 30% more; recount on the target model (tokens)
Disable thinking on Opus 5.5Can't; steer with effort (thinking and effort)
Faster output, same modelFast mode (premium price; 429 or 529 when capacity is out) (fast mode)

Model tier and releases (5.2)

ClueAnswer
Where to startOpus 5.5; tune effort before switching; escalate to Fable 5.2 only if needed (trade-offs)
Zero data retention requiredExcludes Fable and Mythos (Covered Models) (constraints)
Moving to a new modelMigration guide, effort sweep, regression suite, shadow traffic (planning)

Cost (5.3)

ClueAnswer
Bill too high: where to lookSplit into uncached input, writes, reads and output; fix the largest (cost driver)
Long fixed prefix, changing tailOne breakpoint at the end of the stable prefix; layered for different rates (breakpoints)
Cache misses every requestThe prefix changes, or it's under the minimum; use a mid-conversation system message (breakpoints)

Domain 6: Prompt and Context Engineering

Long sessions (6.1)

ClueAnswer
Most tokens are old tool resultsContext editing clear_tool_uses_20250919, or trim results (pruning)
Conversation itself is longCompaction: compact_20260112 at a threshold, or on demand; send the block back (compaction)
Task changed or context is staleFresh session with a structured summary (start fresh)

Prompt revision (6.2)

ClueAnswer
Sarcasm filed as praiseRule with the reason plus examples of the hard case; add it to the regression set (revision)
One example copied word for wordUse three to five diverse examples (examples)
Rules beside customer text in the user turnRole, rules and policy in the system prompt; data in the user turn (placement)

Structured output (6.3)

ClueAnswer
Valid JSON, wrong totalSchemas fix shape, not meaning: validate in code (validation)
Parse fails on some responsesCheck stop_reason first: refusal and max_tokens break the guarantee (guarantees)
JSON somewhere in proseString-aware parser for the first complete object, then validate; not a greedy regex (fallbacks)

Grounding (6.4)

ClueAnswer
Assistant invents a policyDocuments only, an exact NOT_FOUND, citations, withhold uncited answers (not found)
Citations for retrieved passagessearch_result blocks with source and title, citations enabled (citing)
Whole corpus or retrieval?Small and stable: send all, cached; large or changing: retrieve (full or retrieve)

Domain 7: Security and Safety

Injection and jailbreaks (7.1)

ClueAnswer
Attacker writes the email, not the userIndirect injection: tool results only, JSON-encoded, screened, policy, least privilege (indirect)
Highest-risk agentUntrusted input plus sensitive data plus an outbound action (exposure)
Screening call refusesTreat the refusal as suspected (layers)

Deterministic guardrails (7.2)

ClueAnswer
Must never drop a table, even if persuadedRead-only credentials, plus deny rules and a PreToolUse hook (six layers)
Does a hook deny hold in bypassPermissions?Yes: order is hooks, deny, ask, mode, allow, canUseTool (order)
Bash could reach anythingThe OS sandbox: write limits and a domain allowlist (not on native Windows) (sandbox)

Keys and credentials (7.3)

ClueAnswer
Key in the web page's JavaScriptBack-end proxy holds the key; App Attest for native apps (never in the client)
CI or production credentialService account key, or Workload Identity Federation (no static key) (credentials)
Key may have leakedDisable (reversible), rotate, then delete (permanent) (leaks)

Domain 8: Tools and MCP

Tool design (8.1)

ClueAnswer
Tool returns the whole 40-field API objectShape it to a few worked-out fields with a next action (shaping)
Refund on the model's say-soQueue for approval, validate in the tool (approval)
Who runs the tool?Client tools in your app; server tools (web, code execution, MCP connector) on Anthropic's side (execution side)

MCP servers (8.2)

ClueAnswer
Local developer toolstdio; shared or remote is Streamable HTTP with bearer tokens (transport)
Connector can't reach our serverIt needs public HTTPS and supports tools only, not stdio, resources or prompts (connector)
Error text hidden from the modelRaise ToolError; plain exceptions are masked in SDK 2.x (server)

Capability selection (8.3)

ClueAnswer
House style for reportsA Skill: about 100 tokens until used; no network on the API (Skills)
Many teams need the same live systemAn MCP server maintained by its owners (selecting)
One app, one internal lookupA custom tool (selecting)
