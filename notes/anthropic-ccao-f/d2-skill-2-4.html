2.4: Output Adaptation and Format Selection

Getting a good answer into the form its reader needs: a quick message, an editable document, rows for a spreadsheet, figures calculated exactly, or a finished file, and knowing which form each situation calls for.

Overview

Skill 2.4

Output Adaptation and Format Selection: "Applying editing, adaptation, and output-format selection to a raw Claude output for its audience or delivery channel, including inline responses, artifacts, structured data, code-executed results for computation that must be exact, and Skill-produced documents."

Exam items describe content and where it's going, and ask which format or feature fits. Choosing between Projects, Skills, Research and analysis before the work starts is skill 3.1; this skill is about the shape of the result.

Adapt one answer to each reader, place and required precision

Skill 2.4The same content, adapted five ways.

Take a long chat analysis of November’s returns that has to reach five places: the store managers’ chat channel, a leadership brief, the returns tracker spreadsheet, the finance team, and a regional review meeting.

adaptations.txt (Adaptation prompts) 
Raw output: a long chat answer analysing November's returns (themes, figures, recommendations).

1. Team chat message (inline response)
   "Turn this into a five-line update for the store managers' channel: the one change that matters,
    the figure that shows it, and what we need from them. No headings."

2. One-page brief for the leadership meeting (artifact, document template)
   "Make this a one-page brief as a document: headline, three findings with their figures, one
    recommendation each. I'll edit it before exporting to Word."

3. Rows for the returns tracker (structured data)
   "List each product category as one row with these columns: category, units returned, return rate,
    top reason. Output only the table, nothing else, so I can paste it into the spreadsheet."

4. Refund totals for finance (code-executed result)
   "Using returns_nov.csv, calculate total refunds by payment method with code, show the totals and
    the calculation, and round only at the end." -> numbers that must be exact are computed, not
    written from memory of the data.

5. Slides for the regional review (Skill-produced document)
   "Create a six-slide PowerPoint from the brief: title, one slide per finding with its chart, a
    recommendations slide and a next-steps slide." -> a downloadable .pptx, checked before it's sent.

Each prompt names the destination, the reader and the exact shape. The deciding questions: who reads it, where (a chat window, a meeting, a spreadsheet), whether it will be edited further, and whether any number has to be exact.

Use inline replies for short text, and state the length and form

Skill 2.4Answers that live in the conversation.

The plain chat reply suits short answers, explanations, quick drafts and text you'll paste into a message or email. State length and form explicitly ("five lines, no headings"), because the default chat style may not suit the channel. Anthropic's prompting advice applies: say what you want instead of what you don't, and match your own prompt's style to the output; a prompt full of markdown tends to produce markdown.

Use an artifact for content people will edit, reuse or share

Skill 2.4Content you'll put in front of someone.

  • What they are: the Help Center calls an artifact "anything Claude makes for you that you'd put in front of someone". It sits in a window beside the chat, where you can revisit, edit and share it.
  • When Claude makes one: for content that is significant and self-contained (typically over 15 lines), likely to be edited or reused outside the chat, and makes sense without the conversation. You can also simply ask for one.
  • What they can be: documents, code, single-page websites, diagrams and flowcharts, dashboards, images, and small interactive tools.
  • Templates: Docs, Slides and Design on every plan; Data, Sheets and Whiteboards on paid plans (the latter two in beta); Motion on Team and Enterprise.
  • Editing: ask Claude for changes, edit directly, or highlight text and use "Edit with Claude". Editing an earlier message creates a separate version of the chat with its own artifacts, so you can try another direction without losing the first.
  • Delivery: template artifacts export to Word, PDF, PowerPoint, Google formats and HTML. Artifacts start private, and a person you share one with uses their own Claude account and limits.
  • Requirement: artifacts need the code execution and file creation capability switched on.

Define structured data exactly, allow for gaps, and spot-check it

Skill 2.4Rows and fields another tool will consume.

  • Define it exactly: for data going into a spreadsheet, tracker or another system, name the columns or fields, in order, and ask for only the table (or CSV, or list) with nothing around it, so it pastes cleanly.
  • Allow for gaps: say what to put when a value is unknown ("leave blank" or "n/a") so Claude doesn't invent one to fill the cell.
  • Check it: spot-check rows against the source before importing; structure makes errors look tidy, not correct.

Calculate exact numbers with code execution, not prose

Skill 2.4Numbers that must be exact are calculated, not written.

  • Why: when Claude reads data and writes totals in prose, the figures can look right and be slightly off. With code execution and file creation turned on, Claude can run Python on an uploaded file and show the calculation, so the result is computed and you can see how.
  • What else it does: analyses CSV and TSV files, makes charts, and creates and edits Excel, Word, PowerPoint and PDF files, which you download or save to Google Drive. Files can be up to 30 MB.
  • Availability: all plans, on web, desktop and mobile. Individuals turn it on in Settings, under Capabilities; on Team and Enterprise it's on by default and owners control it.
  • A security note from the Help Center: hidden instructions in a file or web page could try to make Claude run untrusted code or send connected data out. On Team and Enterprise, admins control network access. Keep an eye on what Claude does with files from unknown sources.

Use document Skills for finished files, and still check them

Skill 2.4Finished files in standard formats.

  • Pre-built Skills: Anthropic provides document Skills for PowerPoint, Excel, Word and PDF, available in claude.ai. Claude uses them automatically when you ask for one of those files, producing a real downloadable file rather than text to copy.
  • Your own Skills: on paid plans with code execution on, custom Skills such as a house report format can be uploaded, so every deck or report follows your template (skill 4.3).
  • Still check it: a polished file is easy to forward unread. Open it and check the figures, charts and wording before it goes out (skill 2.3).

Adapt the content to the audience, then make a final human edit

Skill 2.4Adapting the content, not just the container.

  • Length and order: the managers get the one change that matters first; leadership gets findings with figures; finance gets totals.
  • Vocabulary and tone: technical detail for analysts, plain language for customers, the organisation's voice for anything external.
  • What to leave out: internal reasoning, caveats meant for you, and detail the reader can't act on.
  • Your own edits: adaptation isn't only a prompt. A final human edit for accuracy, names and tone is part of delivering it, especially for external work.

"Paste the chat answer into the slide deck" or "ask Claude to write the totals into the report" are the usual wrong choices. Use a file or Skill for the deck, and code execution for figures that must be exact.

Practice questions

Exam-style questions written for these notes. Decide your answer before reading the explanation.

Question 1
Scenario
Finance needs exact return totals from a CSV export. Which format fits?
  1. A. Totals written in the chat reply
  2. B. Code-executed analysis that computes and shows the calculation
  3. C. An artifact with estimated figures
  4. D. A Skill
Answer
B
Why
Numbers that must be exact are calculated, not written.
Question 2
Scenario
Rows must paste cleanly into a tracker spreadsheet. What should the request specify?
  1. A. Nothing
  2. B. The exact columns in order, only the table with nothing around it, and what to put for unknown values
  3. C. A friendly tone
  4. D. Bold headings
Answer
B
Why
Defined structure pastes cleanly; allowed gaps stop invented values.
Question 3
Scenario
A regional meeting needs slides. What is the better choice than pasting the chat answer?
  1. A. Paste it anyway
  2. B. A PowerPoint file from the document Skill, then check it
  3. C. An inline reply
  4. D. A CSV
Answer
B
Why
A real file suits the delivery; checking is still yours.
Question 4
Scenario
When should content become an artifact rather than an inline reply?
  1. A. Always
  2. B. When it is substantial, self-contained and will be edited, reused or shared
  3. C. Never
  4. D. Only for code
Answer
B
Why
Artifacts are what you’d put in front of someone.

Key takeaways

  • Choose the format by reader, channel, whether it will be edited further, and whether numbers must be exact.
  • Inline replies for short answers and pasteable text (state length and form); artifacts for substantial, reusable content, edited beside the chat and exported to Word, PDF, PowerPoint or Google formats.
  • Structured data: name the fields, ask for only the table, say what to do with unknown values, and spot-check before importing.
  • Exact figures come from code execution on the file, with the calculation shown; it also creates Excel, Word, PowerPoint and PDF files (up to 30 MB). Watch for hidden instructions in untrusted files.
  • Document Skills (PowerPoint, Excel, Word, PDF) produce real files; custom Skills apply your templates. Adapt the content for the audience, and give it a final human edit before it goes out.
