3.1: Capability Selection

Knowing which of claude.ai's tools fits a piece of work, and when to combine them: a plain chat, a Project, an artifact, Research, analysis with code, a Skill, a connector to your workplace apps, or memory.

Overview

Skill 3.1

Capability Selection: "Analyzing a work task against the available Claude capabilities, including chat, Projects, Artifacts, research, code-executed analysis, Skills, connectors, and memory, and selecting the combination that best accomplishes the task."

Exam items describe a task and ask which capability, or combination, fits best. The guide's preparation advice includes practising exactly this: choosing among Projects, Skills, Research and code-executed analysis. Earlier pages covered several of these in use: Projects and Research in skill 1.2, and Artifacts, code execution and document Skills in skill 2.4. Managing memory over time is skill 3.3, and choosing the model is skill 3.2.

Sources: the Claude Help Center articles on Projects, Research, artifacts, creating files, connectors, and chat search and memory, plus the Agent Skills overview, checked on 20 November 2026 and paraphrased. The task choices are my own.

Running example. An operations coordinator at the outdoor-gear shop has six jobs this week, from one tricky customer email to a weekly report and a dashboard for store managers.

The capabilities in one sentence each

Skill 3.1What each is for.

  • Chat: a single conversation, best for one-off questions, drafts and thinking things through.
  • Projects: self-contained workspaces with their own chats, knowledge files and instructions, for ongoing work that reuses the same material.
  • Artifacts: substantial, self-contained content in its own window (documents, slides, dashboards, small tools) to edit, export and share.
  • Research: several searches that build on each other, across the web and connected apps, for questions that need investigation (paid plans).
  • Code-executed analysis: Claude runs code on your files, for exact calculations, charts, and creating Excel, Word, PowerPoint or PDF files.
  • Skills: packaged instructions and scripts Claude loads when relevant, including Anthropic's document Skills and your own, for repeatable formats and procedures.
  • Connectors: access to your workplace apps (drive, email, calendar, chat, ticketing) so Claude can read and act there with your permissions.
  • Memory: what Claude keeps from past chats about you and your work, so you don't repeat it each time.

Most real work needs a combination. The weekly report is a Project (same files and rules every week), plus code-executed analysis (exact figures), plus a Skill (the same layout every time). Using only one of them leaves a gap: a plain chat each Monday means re-uploading files and re-explaining the format; a Project without code risks estimated figures.

Connectors

Skill 3.1When the material lives in your workplace apps.

  • What they do: let Claude search, read and act in services such as Google Drive, Gmail and Calendar, Slack, GitHub, Microsoft 365 or Linear. They're available from the connectors directory, or as custom connectors for any service that supports MCP.
  • Permissions: Claude inherits your permissions in each service, so it can't see what you can't. On Team and Enterprise, owners enable connectors first, can set each tool to always allowed, needing approval or blocked, and each person still signs in.
  • Turning them on: use the "+" or "/" menu in a chat. With ten or more active, the Help Center suggests loading tools on demand.
  • Cautions:
    • connect only services you trust and need, and disconnect ones you no longer use;
    • third-party services process data on their own infrastructure, which may be outside the US even if you've chosen US-only processing for Claude;
    • custom connectors must be reachable from the internet.

Memory

Skill 3.1When Claude should carry knowledge between chats.

  • What it keeps: Claude saves memory as topics while you chat: your role, projects, people, communication style and preferences. You can also say "remember this". Sensitive topics are left out unless you opt in, and some data, such as government ID numbers and financial account numbers, is never stored.
  • Per Project: each Project has its own memory. Inside a Project, Claude uses that Project's memory plus your general memory, but not other Projects'.
  • Memory or Project instructions? Memory suits preferences that apply across your work. Project instructions suit rules for one area of work that everyone in the Project should get.
  • When not to: for a one-off sensitive chat, an incognito chat isn't saved to history or memory. Keeping memory accurate over time is skill 3.3.

Questions that decide

Skill 3.1Work through these in order.

  • Is it one-off or recurring? One-off: chat. Recurring with the same material: a Project. Recurring with the same format or procedure: a Skill.
  • Where is the information? In files you have: attach them or use Project knowledge. On the web: Research. In workplace apps: connectors.
  • Must numbers be exact? Use code-executed analysis.
  • Will people use the result directly? An artifact, or a document file.
  • Should Claude know it next time? Memory, or Project instructions for one area of work.

"Use the most powerful option every time", such as Research for a question Claude can answer from an attached file, wastes time and usage; Research also uses limits faster than a normal chat. Choose the simplest combination that does the job.

Key takeaways

  • Chat for one-offs; Projects for recurring work with the same files and rules; Artifacts for content people will use; Research for investigation; code-executed analysis for exact figures and files; Skills for repeatable formats; connectors for workplace data; memory for preferences across chats.
  • Most tasks need a combination: a weekly report is a Project, plus code for the numbers, plus a Skill for the format.
  • Connectors act with your permissions; on Team and Enterprise, owners enable them and can require approval or block tools; connect only what you trust and need.
  • Memory is kept as topics, separately for each Project; use incognito chats for one-off sensitive conversations.
  • Decide by: one-off or recurring, where the information lives, exactness, how the result is used, and whether Claude should remember it. Pick the simplest combination that works.
