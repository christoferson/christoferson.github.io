Classic Load Balancer (Legacy)

  1. Can balance HTT, HTTPS, TCP traffic. (not at the same time)
  2. Can use layer 7 features e.g. sticky sessions
  3. Can use strictly Layer 4 for pure TCP applications
  4. Can perform cross zone load balancing
  5. Responds with 504 error (timeout) if underlying application is not responding.
  6. Not reccomended for new applications, use ALB and NLB
